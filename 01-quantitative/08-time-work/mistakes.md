# Time & Work — Common Mistakes

## 1. Using Days Instead of Work Rate

### Mistake

A can complete a work in 10 days, so writing:

```text
A's 1-day work = 10
```

### Correct

Time and daily work are reciprocals:

```text
1-day work = 1/10
```

### Avoid It

Always convert:

```text
T days → 1/T work per day
```

**Tag:** C — Concept

---

## 2. Adding Completion Times Directly

### Mistake

A takes 10 days and B takes 20 days.

Writing:

```text
10 + 20 = 30 days
```

### Correct

Add their **work rates**:

```text
1/10 + 1/20
= 3/20
```

Therefore:

```text
Time = 20/3 days
```

### Avoid It

```text
Together → Add Rates, Not Days
```

**Tag:** C — Concept

---

## 3. Forgetting That Efficiency and Time Are Inversely Related

### Mistake

Thinking that a person who is twice as efficient takes twice the time.

### Correct

Higher efficiency means less time.

```text
Efficiency ∝ 1/Time
```

If:

```text
A : B efficiency = 2 : 1
```

then:

```text
A : B time = 1 : 2
```

### Avoid It

Remember:

```text
More Efficiency → Less Time
Less Efficiency → More Time
```

**Tag:** C — Concept

---

## 4. Adding Efficiency Ratios Instead of Rates

### Mistake

A takes 10 days and B takes 15 days, then directly treating:

```text
10 + 15
```

as their combined efficiency.

### Correct

Convert time into rates:

```text
A = 1/10
B = 1/15
```

Then add:

```text
1/10 + 1/15 = 1/6
```

### Avoid It

Always work with:

```text
Rate = 1/Time
```

**Tag:** C — Concept

---

## 5. Forgetting to Subtract Work Already Completed

### Mistake

A works alone for 4 days and then B joins, but calculating the remaining work as the full job.

### Correct

First calculate work already completed.

If A takes 12 days:

```text
A's rate = 1/12
```

In 4 days:

```text
4 × 1/12 = 1/3
```

Remaining:

```text
1 - 1/3 = 2/3
```

### Avoid It

Use:

```text
Remaining Work = Total Work - Completed Work
```

**Tag:** R — Reading

---

## 6. Using the Men × Days Formula When Hours Change

### Mistake

Using:

```text
M₁D₁ = M₂D₂
```

when the number of working hours per day is different.

### Correct

Use:

```text
M₁D₁H₁ = M₂D₂H₂
```

### Example

If workers change from 8 hours/day to 6 hours/day, hours must be included.

### Avoid It

Whenever daily working hours appear, use the **MDH formula**.

**Tag:** R — Reading

---

## 7. Getting the Efficiency Percentage Ratio Wrong

### Mistake

A is 25% more efficient than B.

Writing:

```text
A : B = 25 : 100
```

### Correct

B = 100%

A = 125%

Therefore:

```text
A : B = 125 : 100
       = 5 : 4
```

Time ratio is inverse:

```text
A : B time = 4 : 5
```

### Avoid It

For `R% more efficient`:

```text
Efficiency ratio = (100+R) : 100
```

**Tag:** C — Concept

---

## 8. Forgetting to Invert the Ratio for Time

### Mistake

A : B efficiency = `3 : 2`

Writing:

```text
A : B time = 3 : 2
```

### Correct

Time is inversely proportional to efficiency:

```text
A : B time = 2 : 3
```

### Avoid It

```text
Efficiency Ratio → Reverse It → Time Ratio
```

**Tag:** C — Concept

---

## 9. Treating a Leak as Positive Work

### Mistake

A pipe fills a tank in 10 hours and a leak empties it in 20 hours.

Writing:

```text
1/10 + 1/20
```

### Correct

The leak removes water:

```text
1/10 - 1/20
= 1/20
```

### Avoid It

```text
Filling → +
Emptying → -
```

**Tag:** C — Concept

---

## 10. Ignoring the Working Pattern in Alternate-Day Questions

### Mistake

A works on Day 1 and B works on Day 2, but treating them as if they work together every day.

### Correct

Calculate each day's work separately.

Example:

```text
Day 1 → A
Day 2 → B
Day 3 → A
Day 4 → B
```

For one two-day cycle:

```text
Cycle Work = A's work + B's work
```

### Avoid It

Read carefully for words such as:

* alternate days
* every second day
* odd days
* even days
* starts with A

**Tag:** R — Reading

# Quick Mistake Checklist

Before submitting a Time & Work answer:

* [ ] Did I convert time into work rate?
* [ ] Did I use `1/T` for one-day work?
* [ ] Did I add rates rather than completion times?
* [ ] Did I subtract rates where work is being removed?
* [ ] Did I calculate remaining work correctly?
* [ ] Did I invert efficiency and time ratios?
* [ ] Did I check percentage efficiency carefully?
* [ ] Did I include hours when working hours changed?
* [ ] Did I follow the alternate-day pattern?
* [ ] Did I check whether the question asks for work, rate, or time?
