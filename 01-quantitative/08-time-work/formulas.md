# Time & Work — Formulas

## 1. Basic Work Rate

If a person completes work in `T` days:

```text
1-day work = 1/T
```

---

## 2. Total Work

```text
Work = Rate × Time
```

---

## 3. Time

```text
Time = Work/Rate
```

---

## 4. Rate

```text
Rate = Work/Time
```

---

## 5. Two People Together

If A takes `x` days and B takes `y` days:

```text
Combined rate = 1/x + 1/y
```

```text
Time together = xy/(x+y)
```

---

## 6. Three People Together

```text
Combined rate = 1/x + 1/y + 1/z
```

```text
Time = 1/Combined rate
```

---

## 7. One Person's Rate

If A+B rate and A's rate are known:

```text
B's rate = (A+B) rate - A's rate
```

---

## 8. Remaining Work

```text
Remaining Work = Total Work - Work Done
```

---

## 9. Work Done

```text
Work Done = Rate × Time
```

---

## 10. LCM Method

If completion times are:

```text
x, y, z days
```

Take:

```text
Total Work = LCM(x,y,z)
```

Then:

```text
Efficiency = Total Work/Individual Time
```

---

## 11. Efficiency Ratio

```text
Efficiency ∝ 1/Time
```

Therefore:

```text
Efficiency Ratio = Inverse of Time Ratio
```

---

## 12. Efficiency Percentage

If A is `R%` more efficient than B:

```text
A : B efficiency = (100+R) : 100
```

Therefore:

```text
A : B time = 100 : (100+R)
```

---

## 13. Men and Days

For the same work and equal efficiency:

```text
M₁D₁ = M₂D₂
```

---

## 14. Men, Days and Hours

For the same work:

```text
M₁D₁H₁ = M₂D₂H₂
```

---

## 15. Work and Wages

```text
Wages ∝ Work Done
```

If efficiency and time are involved:

```text
Work = Efficiency × Time
```

Therefore:

```text
Wage Ratio = Work Ratio
```

---

## 16. Alternate Days

Calculate work done in one complete cycle:

```text
Cycle Work = Day 1 Work + Day 2 Work + ...
```

Then:

```text
Number of cycles = Total Work/Cycle Work
```

---

## 17. Pipes

Filling pipe:

```text
+1/T
```

Emptying pipe:

```text
-1/T
```

Net rate:

```text
Net Rate = Filling Rate - Emptying Rate
```

---

## 18. Work Percentage

If a person completes `x%` of work:

```text
Work Done = x/100
```

Remaining:

```text
Remaining = (100-x)/100
```

---

## 20. Memory Rules

```text
Days → Take Reciprocal → Rate

Together → Add

Leak/Removal → Subtract

Efficiency ↑ → Time ↓

Same Work:
Men × Days × Hours = Constant
```
