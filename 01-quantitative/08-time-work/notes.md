# Time & Work — Notes

## 1. Basic Idea

Time & Work problems are based on one simple relationship:

```text
Work = Rate × Time
```

If a person completes a job in `T` days:

```text
1 day's work = 1/T
```

So the person completes:

```text
1/T of the work per day
```

---

# 2. Basic Example

A can complete a work in `10 days`.

Therefore:

```text
A's 1-day work = 1/10
```

In `5 days`:

```text
Work = 5 × 1/10
     = 1/2
```

So A completes **50% of the work** in 5 days.

---

# 3. Finding Time from Work Rate

If a person completes:

```text
1/8 of work per day
```

then the total time required is:

```text
8 days
```

Therefore:

```text
Time = 1 / One-day work
```

---

# 4. Work and Efficiency

Efficiency means the amount of work completed in a given time.

If:

```text
A is twice as efficient as B
```

then:

```text
A's work rate : B's work rate = 2 : 1
```

Therefore:

```text
A takes half the time taken by B.
```

### Important Relationship

```text
Efficiency ∝ 1/Time
```

So:

```text
Efficiency ratio = Inverse of time ratio
```

---

# 5. Example — Efficiency

A can complete a work in `10 days` and B can complete it in `20 days`.

Their efficiencies are:

```text
A : B = 1/10 : 1/20
```

Multiply by 20:

```text
A : B = 2 : 1
```

Therefore:

```text
A is twice as efficient as B.
```

---

# 6. A and B Working Together

If:

```text
A completes work in 10 days
B completes work in 15 days
```

Then:

```text
A's 1-day work = 1/10
B's 1-day work = 1/15
```

Together:

```text
1/10 + 1/15
```

LCM = 30:

```text
3/30 + 2/30
= 5/30
= 1/6
```

Therefore, together they complete the work in:

```text
6 days
```

---

# 7. Formula for Two People Working Together

If A completes work in `x` days and B in `y` days:

```text
Combined 1-day work
= 1/x + 1/y
```

Therefore:

```text
Time together = xy/(x+y)
```

### Example

A = 12 days

B = 18 days

```text
Time together
= (12×18)/(12+18)
= 216/30
= 7.2 days
```

---

# 8. Three People Working Together

If A, B and C complete the work in:

```text
x, y and z days
```

then:

```text
Combined work/day
= 1/x + 1/y + 1/z
```

Find the reciprocal to get total time.

---

# 9. Work Done in a Given Number of Days

If A takes `12 days`:

```text
A's 1-day work = 1/12
```

In `4 days`:

```text
4/12 = 1/3
```

So A completes one-third of the work.

---

# 10. Work Remaining

If total work is represented by `1`:

```text
Remaining Work = 1 - Work Done
```

### Example

A completes `3/5` of a job.

Remaining:

```text
1 - 3/5
= 2/5
```

---

# 11. Using LCM as Total Work

Fractions can sometimes become inconvenient.

Suppose:

```text
A = 12 days
B = 18 days
```

Take LCM:

```text
LCM(12,18) = 36
```

Consider total work = `36 units`.

Then:

```text
A's efficiency = 36/12 = 3 units/day
B's efficiency = 36/18 = 2 units/day
```

Together:

```text
3 + 2 = 5 units/day
```

Time:

```text
36/5 = 7.2 days
```

This method is extremely useful in placement questions.

---

# 12. A, B and C Together

Suppose:

```text
A = 10 days
B = 15 days
C = 30 days
```

Take:

```text
Total work = LCM(10,15,30)
           = 30 units
```

Efficiency:

```text
A = 30/10 = 3
B = 30/15 = 2
C = 30/30 = 1
```

Together:

```text
3 + 2 + 1 = 6 units/day
```

Time:

```text
30/6 = 5 days
```

---

# 13. One Person Leaves

A and B together complete a work in `6 days`.

A alone completes it in `10 days`.

Find B's time.

Using rates:

```text
A+B = 1/6
A = 1/10
```

Therefore:

```text
B = 1/6 - 1/10
```

LCM = 30:

```text
B = 5/30 - 3/30
  = 2/30
  = 1/15
```

Therefore B alone takes:

```text
15 days
```

---

# 14. One Person Joins Later

Suppose A can complete a job in `12 days`.

A works alone for `4 days`.

Work completed:

```text
4/12 = 1/3
```

Remaining:

```text
2/3
```

If B joins A, use their combined rate to complete the remaining work.

---

# 15. A and B Alternate Days

Sometimes workers do not work simultaneously.

Example:

```text
A → Day 1
B → Day 2
A → Day 3
B → Day 4
```

Calculate the work done in one complete cycle.

If:

```text
A = 1/10 per day
B = 1/20 per day
```

Then two-day work:

```text
1/10 + 1/20
= 3/20
```

Number of complete cycles can then be calculated.

---

# 16. Work and Wages

Wages are distributed according to **work done**, not simply time spent.

If:

```text
A's efficiency = 3 units/day
B's efficiency = 2 units/day
```

and they work for the same number of days:

```text
A's work : B's work = 3 : 2
```

Therefore their wages should be:

```text
3 : 2
```

---

# 17. Different Working Times

If workers have different efficiencies and work for different durations:

```text
Work = Efficiency × Time
```

Therefore:

```text
A's work = A efficiency × A time
B's work = B efficiency × B time
```

Then compare their work for wage distribution.

---

# 18. Men and Days

If all workers have equal efficiency:

```text
Men × Days = Constant Work
```

Therefore:

```text
M₁D₁ = M₂D₂
```

### Example

10 men complete a work in 12 days.

How many men are needed for 8 days?

```text
10 × 12 = M × 8
```

```text
M = 120/8
  = 15
```

Therefore:

```text
15 men
```

---

# 19. Men, Days and Hours

When daily working hours also change:

```text
Men × Days × Hours = Constant
```

Therefore:

```text
M₁D₁H₁ = M₂D₂H₂
```

### Example

8 workers working 6 hours/day complete a job in 10 days.

How many workers are needed to complete it in 8 days working 5 hours/day?

```text
8 × 10 × 6 = M × 8 × 5
```

```text
480 = 40M
```

```text
M = 12
```

---

# 20. Efficiency and Time Ratio

If:

```text
A is 50% more efficient than B
```

then:

```text
A : B efficiency = 150 : 100
                  = 3 : 2
```

Time ratio is inverse:

```text
A : B time = 2 : 3
```

So if B takes `15 days`:

```text
A takes 10 days
```

---

# 21. Percentage Efficiency

If A is `25%` more efficient than B:

```text
A efficiency = 125% of B
```

Therefore:

```text
A : B = 5 : 4
```

Time ratio:

```text
A : B = 4 : 5
```

---

# 22. Pipes and Cisterns Connection

Pipes and cisterns use the same work-rate concept.

A filling pipe:

```text
Positive work
```

A leakage pipe:

```text
Negative work
```

If a pipe fills a tank in `10 hours`:

```text
Rate = 1/10 tank/hour
```

If a leak empties it in `20 hours`:

```text
Rate = -1/20 tank/hour
```

Net rate:

```text
1/10 - 1/20
= 1/20
```

Tank fills in:

```text
20 hours
```

---

# 23. Work Equivalence

If:

```text
A works for 4 days
B works for 6 days
```

and their efficiencies are:

```text
A = 3 units/day
B = 2 units/day
```

then:

```text
A's work = 4 × 3 = 12 units
B's work = 6 × 2 = 12 units
```

They perform equal work.

# 25. Common Traps

### Trap 1 — Adding Days

If A takes 10 days and B takes 20 days:

```text
Wrong:
10 + 20 = 30
```

Correct:

```text
Work rates:
1/10 + 1/20
= 3/20
```

---

### Trap 2 — Forgetting Reciprocal

If someone completes work in 8 days:

```text
1-day work = 1/8
```

not `8`.

---

### Trap 3 — Efficiency vs Time

Higher efficiency means less time.

```text
Efficiency ↑ → Time ↓
Efficiency ↓ → Time ↑
```

---

### Trap 4 — Men and Days

More men generally means fewer days for the same work.

```text
M × D = Constant
```

---

# 26. Exam Strategy

For most Time & Work questions:

### Step 1

Convert completion time into daily work.

```text
1/T
```

### Step 2

Add or subtract rates.

```text
Together → Add
Leak/Leaving → Subtract
```

### Step 3

Find remaining work if necessary.

```text
Remaining = Total - Completed
```

### Step 4

Divide remaining work by current rate.

```text
Time = Remaining Work / Rate
```

### Step 5

For workers/days/hours:

```text
M × D × H = Constant
```

### Memory Trick

```text
TIME → RECIPROCAL → RATE

TOGETHER → ADD RATES

LEAK/REMOVAL → SUBTRACT RATES

MORE EFFICIENCY → LESS TIME
```
