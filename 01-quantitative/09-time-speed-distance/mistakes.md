# Time, Speed & Distance — Common Mistakes

## 1. Taking Arithmetic Average of Speeds

### Mistake

Using:

```text
Average Speed = (S₁ + S₂)/2
```

for every average-speed question.

### Why it is wrong

This works only when the **time spent at both speeds is equal**.

For equal distances, the correct formula is:

```text
Average Speed = 2S₁S₂/(S₁+S₂)
```

### How to Avoid

Always ask:

> Are the distances equal or are the times equal?

---

## 2. Mixing km/h and m/s

### Mistake

Using:

```text
Distance = 100 m
Speed = 36 km/h
```

directly in:

```text
Time = Distance/Speed
```

### Why it is wrong

The units are different.

Convert:

```text
36 km/h = 10 m/s
```

Then:

```text
Time = 100/10
     = 10 seconds
```

### How to Avoid

Remember:

```text
km/h → m/s = ×5/18

m/s → km/h = ×18/5
```

---

## 3. Using the Wrong Relative Speed

### Mistake

Adding speeds when two objects move in the same direction.

### Why it is wrong

When objects move in the same direction, the gap changes according to the **difference** in their speeds.

```text
Same Direction → Difference
Opposite Direction → Sum
```

### Example

```text
80 km/h and 50 km/h
```

Same direction:

```text
Relative Speed = 80-50
               = 30 km/h
```

---

## 4. Forgetting Both Lengths in Train-Platform Problems

### Mistake

For a train crossing a platform, using only the platform length.

### Why it is wrong

The entire train must pass completely over the platform.

Therefore:

```text
Distance = Train Length + Platform Length
```

### How to Avoid

Remember:

```text
Pole → Train Length

Platform → Train Length + Platform Length
```

---

## 5. Forgetting Both Train Lengths

### Mistake

When two trains cross each other, using only one train's length.

### Why it is wrong

Both trains must completely pass each other.

Therefore:

```text
Distance = L₁ + L₂
```

### How to Avoid

For two trains:

```text
Total Distance = L₁ + L₂
```

Then divide by the appropriate relative speed.

---

## 6. Confusing Speed Percentage with Time Percentage

### Mistake

Thinking that if speed increases by `25%`, time decreases by exactly `25%`.

### Why it is wrong

For the same distance, speed and time are inversely proportional.

If speed increases by `25%`:

```text
New Speed = 125% of Old Speed
```

Therefore:

```text
New Time = 100/125
         = 80% of Old Time
```

So time decreases by:

```text
20%
```

### How to Avoid

Use:

```text
Speed ↑ by R%
Time ↓ by R/(100+R) × 100%
```

---

## 7. Reversing Upstream and Downstream Formulas

### Mistake

Writing:

```text
Upstream = Boat + Stream
```

### Why it is wrong

The stream helps the boat downstream and opposes it upstream.

Correct:

```text
Downstream = Boat + Stream

Upstream = Boat - Stream
```

### How to Avoid

Remember:

```text
With Stream → Add

Against Stream → Subtract
```

---

## 8. Misreading Race Lead

### Mistake

If A beats B by `20 m` in a `200 m` race, assuming B also travels `200 m`.

### Why it is wrong

When A finishes 200 m, B has covered only:

```text
200 - 20 = 180 m
```

Therefore:

```text
Speed A : Speed B
= 200 : 180
= 10 : 9
```

### How to Avoid

For:

> A beats B by `x` metres in a race of `L` metres

use:

```text
A : B = L : (L-x)
```

---

## 9. Using the Wrong Formula on Circular Tracks

### Mistake

Using the sum of speeds when two runners move in the same direction.

### Why it is wrong

For runners moving in the same direction, one runner must gain one complete lap on the other.

Therefore:

```text
Same Direction:
Time = Track Length/|S₁-S₂|
```

For opposite directions:

```text
Time = Track Length/(S₁+S₂)
```

### How to Avoid

Use the same relative-speed rule:

```text
Same → Difference

Opposite → Sum
```

---

## 10. Ignoring the Actual Condition of the Question

### Mistake

Immediately applying a memorized formula without checking what is constant.

For example:

```text
Speed = 40 km/h
Time = 5 hours
```

and speed becomes `50 km/h`.

Some students calculate the new time using an incorrect percentage shortcut.

### Why it is wrong

The important condition is:

> **Distance remains the same.**

Therefore:

```text
S₁T₁ = S₂T₂
```

```text
40 × 5 = 50 × T₂
```

```text
T₂ = 4 hours
```

### How to Avoid

Before solving, identify:

* Is distance constant?
* Is time constant?
* Are distances equal?
* Are times equal?
* Same direction or opposite?
* Are units compatible?

Before submitting an answer, check:

* [ ] Did I convert km/h and m/s correctly?
* [ ] Did I use total distance / total time for average speed?
* [ ] Are the distances equal or the times equal?
* [ ] Did I use difference for same direction?
* [ ] Did I use sum for opposite direction?
* [ ] Did I include both train lengths?
* [ ] Did I include train + platform length?
* [ ] Did I use the correct upstream/downstream formula?
* [ ] Did I account for inverse speed-time relationship?
* [ ] Did I check whether the question asks for a percentage change or actual value?
