# Time, Speed & Distance — Notes

## 1. Basic Concept

Time, Speed & Distance problems are based on one fundamental relationship:

```text
Distance = Speed × Time
```

Therefore:

```text
Speed = Distance/Time
```

```text
Time = Distance/Speed
```

The three quantities are directly connected.

---

# 2. Basic Units

Common units:

| Quantity | Common Units            |
| -------- | ----------------------- |
| Distance | km, m                   |
| Time     | hours, minutes, seconds |
| Speed    | km/h, m/s               |

Before calculating, make sure the units are compatible.

---

# 3. km/h to m/s

To convert `km/h` into `m/s`:

```text id="kq6v9r"
km/h × 5/18 = m/s
```

### Example

Convert `72 km/h` into m/s.

```text id="j8p2mx"
72 × 5/18
= 20 m/s
```

---

# 4. m/s to km/h

To convert `m/s` into `km/h`:

```text id="v5r8cn"
m/s × 18/5 = km/h
```

### Example

Convert `25 m/s` into km/h.

```text id="x3m7pd"
25 × 18/5
= 90 km/h
```

---

# 5. Distance Formula

If speed is `S` and time is `T`:

```text id="q4n8wb"
D = S × T
```

### Example

A car travels at `60 km/h` for `3 hours`.

```text id="z6p2mc"
D = 60 × 3
  = 180 km
```

---

# 6. Speed Formula

```text id="c8v5qa"
S = D/T
```

### Example

A train covers `240 km` in `4 hours`.

```text id="r3m9kd"
S = 240/4
  = 60 km/h
```

---

# 7. Time Formula

```text id="h7x2pn"
T = D/S
```

### Example

A car travels `150 km` at `50 km/h`.

```text id="m4q8vb"
T = 150/50
  = 3 hours
```

---

# 8. Average Speed

Average speed is:

```text id="s9c3wx"
Average Speed = Total Distance/Total Time
```

It is **not generally** the arithmetic average of speeds.

---

# 9. Equal Distance — Average Speed

If equal distances are travelled at speeds `x` and `y`:

```text id="j2m6pf"
Average Speed = 2xy/(x+y)
```

### Example

A person travels equal distances at `40 km/h` and `60 km/h`.

```text id="t8v4cn"
Average Speed
= 2(40)(60)/(40+60)
= 4800/100
= 48 km/h
```

---

# 10. Equal Time — Average Speed

If equal amounts of time are spent at speeds `x` and `y`:

```text id="n5q7ra"
Average Speed = (x+y)/2
```

### Example

A car travels for 2 hours at `40 km/h` and 2 hours at `60 km/h`.

```text id="b3x8km"
Average Speed = (40+60)/2
              = 50 km/h
```

---

# 11. Important Difference

### Equal Distance

Use:

```text id="1f6v9x"
2xy/(x+y)
```

### Equal Time

Use:

```text id="7q2mca"
(x+y)/2
```

This is one of the most common TSD traps.

---

# 12. Time Conversion

```text
1 hour = 60 minutes
1 minute = 60 seconds
1 hour = 3600 seconds
```

Therefore:

```text id="k8w4sp"
1 minute = 1/60 hour
```

and:

```text id="p6m2vz"
1 second = 1/3600 hour
```

---

# 13. Distance Conversion

```text
1 km = 1000 m
```

Therefore:

```text id="w3c7nb"
1 m = 1/1000 km
```

---

# 14. Relative Speed

Relative speed is used when two objects are moving relative to each other.

### Same Direction

```text id="f5q9xm"
Relative Speed = Difference of Speeds
```

```text id="v7n3kc"
|S₁-S₂|
```

### Opposite Directions

```text id="a2m8pd"
Relative Speed = Sum of Speeds
```

```text id="h4x6vr"
S₁+S₂
```

---

# 15. Example — Same Direction

A car moves at `70 km/h`.

Another car moves at `50 km/h` in the same direction.

Relative speed:

```text id="r9c5wb"
70 - 50 = 20 km/h
```

So the faster car gains `20 km` every hour.

---

# 16. Example — Opposite Directions

Two cars move towards each other at:

```text
60 km/h
40 km/h
```

Relative speed:

```text id="y8m2qx"
60 + 40 = 100 km/h
```

---

# 17. Meeting Problems

If two objects start at the same time and move towards each other:

```text id="q3v7na"
Meeting Time
= Initial Distance/(Sum of Speeds)
```

### Example

Two cities are `300 km` apart.

Two cars travel towards each other at `60 km/h` and `40 km/h`.

```text id="n6x4kp"
Time = 300/(60+40)
     = 3 hours
```

---

# 18. Same Direction Catch-Up

If one object is behind another:

```text id="w5m8cz"
Catch-up Time
= Distance Gap/Relative Speed
```

For same direction:

```text id="p2r7vd"
Relative Speed = Faster Speed - Slower Speed
```

---

# 19. Example — Catch-Up

A runs at `8 m/s`.

B runs at `5 m/s`.

A is `30 m` behind B.

```text id="g9x3bm"
Relative Speed = 8 - 5
               = 3 m/s
```

Catch-up time:

```text id="s4k8qn"
30/3 = 10 seconds
```

---

# 20. Trains

Train problems generally involve:

* Length of train
* Length of platform
* Speed
* Time
* Relative speed

The key idea is:

```text
Time = Distance/Speed
```

---

# 21. Train Crossing a Pole

When a train crosses a pole, the distance travelled is equal to the **length of the train**.

```text id="h2m7pc"
Time = Train Length/Speed
```

### Example

A train is `200 m` long and moves at `20 m/s`.

```text id="c6v9wr"
Time = 200/20
     = 10 seconds
```

---

# 22. Train Crossing a Platform

When a train completely crosses a platform:

```text id="x8q3ma"
Distance = Train Length + Platform Length
```

Therefore:

```text id="j5n7kd"
Time = (Train Length + Platform Length)/Speed
```

---

# 23. Two Trains Crossing Each Other

### Opposite Directions

Use:

```text id="v4p8cs"
Relative Speed = S₁ + S₂
```

Distance:

```text id="t6m2xb"
L₁ + L₂
```

Therefore:

```text id="d9q5rn"
Time = (L₁+L₂)/(S₁+S₂)
```

### Same Direction

```text id="m7c3vk"
Time = (L₁+L₂)/|S₁-S₂|
```

---

# 24. Boats and Streams

Boat problems use:

```text
Downstream Speed = Boat Speed + Stream Speed
```

```text
Upstream Speed = Boat Speed - Stream Speed
```

---

# 25. Finding Boat Speed

If downstream speed is `D` and upstream speed is `U`:

```text id="q8v4mc"
Boat Speed = (D+U)/2
```

---

# 26. Finding Stream Speed

```text id="p3x7bn"
Stream Speed = (D-U)/2
```

### Example

Downstream = `18 km/h`

Upstream = `10 km/h`

Boat speed:

```text id="f6m2zr"
(18+10)/2
= 14 km/h
```

Stream speed:

```text id="k9c5wd"
(18-10)/2
= 4 km/h
```

---

# 27. Circular Track

When two runners move on a circular track:

### Same Direction

Meeting/overtaking time:

```text id="z7n3qp"
Track Length/|S₁-S₂|
```

### Opposite Directions

Meeting time:

```text id="b4m8cx"
Track Length/(S₁+S₂)
```

---

# 28. Multiple Rounds

If a runner completes one round in `T` seconds:

```text id="r5q2vk"
Time for n rounds = nT
```

If two runners complete a round in `T₁` and `T₂`:

For same-direction meeting:

```text id="y6c9pm"
Meeting Time = L/|S₁-S₂|
```

---

# 29. Speed-Time Inverse Relationship

For the same distance:

```text id="h8m4qs"
Speed ∝ 1/Time
```

Therefore:

```text id="k3v7xn"
S₁T₁ = S₂T₂
```

### Example

A person travels a fixed distance at `40 km/h` in 6 hours.

At `60 km/h`:

```text id="c5q9wb"
40 × 6 = 60 × T
```

```text id="m2x8vd"
T = 4 hours
```

---

# 30. Percentage Change in Speed and Time

For the same distance:

If speed increases by `x%`:

```text id="p7n3ka"
New Time
= Old Time × 100/(100+x)
```

### Example

Speed increases by `25%`.

```text id="s4v8mc"
New Time
= Old Time × 100/125
= 4/5 of Old Time
```

So time decreases by:

```text id="j6q2rp"
1 - 4/5 = 1/5 = 20%
```

---

# 31. If Speed Decreases

If speed decreases by `x%`:

```text id="w9m5xb"
New Time
= Old Time × 100/(100-x)
```

Example: speed decreases by `20%`.

```text id="a3c7vn"
New Time
= Old Time × 100/80
= 5/4 Old Time
```

Time increases by:

```text id="d8q4ks"
25%
```

---

# 32. Late and Early Problems

If a person travels at one speed and reaches late, but at a higher speed reaches early:

The difference in travel times is used.

For distance `D`:

```text id="n5v2pc"
D/S₁ - D/S₂ = Time Difference
```

This type of question often requires solving for distance or speed.

---

# 33. Average Speed in Multiple Segments

Always use:

```text id="x4m8qz"
Average Speed = Total Distance/Total Time
```

For example:

```text
Segment 1 → 100 km in 2 hours
Segment 2 → 150 km in 3 hours
```

Total:

```text id="r7c3kp"
Distance = 250 km
Time = 5 hours
```

Therefore:

```text id="f2n6vb"
Average Speed = 250/5
              = 50 km/h
```

# 35. Common Traps

### Trap 1 — Average of Speeds

Do not automatically use:

```text
(S₁+S₂)/2
```

unless the **time spent is equal**.

---

### Trap 2 — km/h and m/s

Do not mix:

```text
km with seconds
```

or:

```text
metres with hours
```

Convert units first.

---

### Trap 3 — Relative Speed

```text
Same Direction → Difference
Opposite Direction → Sum
```

---

### Trap 4 — Train and Platform

For a train crossing a platform:

```text
Train Length + Platform Length
```

not just platform length.

---

# 36. Exam Strategy

### Step 1

Write:

```text
D = ?
S = ?
T = ?
```

### Step 2

Check units.

### Step 3

Use:

```text
D = S × T
```

### Step 4

For two moving objects, determine:

```text
Same Direction → Difference
Opposite Direction → Sum
```

### Step 5

For trains, identify the total distance that must be covered.

### Memory Trick

```text
DST Triangle:

      D
     ---
     S T

D = S×T
S = D/T
T = D/S
```

And:

```text
Same Direction → SUBTRACT

Opposite Direction → ADD

Equal Distance → 2xy/(x+y)

Average Speed → Total Distance/Total Time
```
