# Time, Speed & Distance — Formulas

## 1. Basic Formula

```text
D = S × T
```

```text
S = D/T
```

```text
T = D/S
```

---

## 2. Speed Conversion

```text
km/h → m/s = × 5/18
```

```text
m/s → km/h = × 18/5
```

---

## 3. Time Conversion

```text
1 hour = 60 minutes = 3600 seconds
```

```text
1 minute = 60 seconds
```

---

## 4. Distance Conversion

```text
1 km = 1000 m
```

---

## 5. Average Speed

```text
Average Speed = Total Distance/Total Time
```

---

## 6. Equal Distance Average Speed

For speeds `x` and `y`:

```text
Average Speed = 2xy/(x+y)
```

---

## 7. Equal Time Average Speed

```text
Average Speed = (x+y)/2
```

---

## 8. Relative Speed

Same direction:

```text
Relative Speed = |S₁-S₂|
```

Opposite direction:

```text
Relative Speed = S₁+S₂
```

---

## 9. Meeting Time

```text
Meeting Time = Distance/Relative Speed
```

For opposite directions:

```text
Time = Distance/(S₁+S₂)
```

---

## 10. Catch-Up Time

```text
Catch-Up Time = Gap/(S_fast-S_slow)
```

---

## 11. Train Crossing a Pole

```text
Time = Train Length/Speed
```

---

## 12. Train Crossing a Platform

```text
Time = (Train Length + Platform Length)/Speed
```

---

## 13. Two Trains — Opposite Direction

```text
Time = (L₁+L₂)/(S₁+S₂)
```

---

## 14. Two Trains — Same Direction

```text
Time = (L₁+L₂)/|S₁-S₂|
```

---

## 15. Boats and Streams

```text
Downstream = Boat + Stream
```

```text
Upstream = Boat - Stream
```

---

## 16. Boat Speed

```text
Boat Speed = (Downstream + Upstream)/2
```

---

## 17. Stream Speed

```text
Stream Speed = (Downstream - Upstream)/2
```

---

## 18. Circular Track

Same direction:

```text
Meeting Time = Track Length/|S₁-S₂|
```

Opposite direction:

```text
Meeting Time = Track Length/(S₁+S₂)
```

---

## 19. Same Distance

```text
S₁T₁ = S₂T₂
```

Therefore:

```text
S₁/S₂ = T₂/T₁
```

---

## 20. Speed Increase

If speed increases by `R%`:

```text
New Time = Old Time × 100/(100+R)
```

---

## 21. Speed Decrease

If speed decreases by `R%`:

```text
New Time = Old Time × 100/(100-R)
```

---

## 22. Percentage Change Relationship

For the same distance:

If speed increases by `R%`, time decreases by:

```text
R/(100+R) × 100%
```

If speed decreases by `R%`, time increases by:

```text
R/(100-R) × 100%
```

---

## 23. Late/Early Problems

```text
D/S₁ - D/S₂ = Time Difference
```

## 25. Memory Rules

```text
D = ST

Same Direction → Difference

Opposite Direction → Sum

Train + Pole → Train Length

Train + Platform → Both Lengths

Average Speed → Total Distance/Total Time

Equal Distance → 2xy/(x+y)

Speed ↑ → Time ↓

Speed ↓ → Time ↑
```
