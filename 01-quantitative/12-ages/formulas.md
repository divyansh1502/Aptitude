# Ages — Formulas

## 👤 Basic Age Formulas

| Situation                      | Formula                    |
| ------------------------------ | -------------------------- |
| `n` years ago                  | `Present Age - n`          |
| After `n` years                | `Present Age + n`          |
| Present age from `n` years ago | `Past Age + n`             |
| Present age from future age    | `Future Age - n`           |
| Age difference                 | `Larger Age - Smaller Age` |

---

## 🔒 Constant Age Difference

```text
Age Difference = Constant
```

If:

```text
A - B = D
```

Then after or before any number of years:

```text
A - B = D
```

---

## ⚖️ Ratio of Ages

If:

```text
A : B = a : b
```

Then:

```text
A = ax
B = bx
```

---

## ➕ Ratio + Sum

If:

```text
A : B = a : b
A + B = S
```

Then:

```text
x = S/(a+b)
```

Therefore:

```text
A = aS/(a+b)
B = bS/(a+b)
```

---

## ➖ Ratio + Difference

If:

```text
A : B = a : b
B - A = D
```

Then:

```text
x = D/(b-a)
```

Therefore:

```text
A = aD/(b-a)
B = bD/(b-a)
```

---

## 📊 Average Age

```text
Average Age
= Total Age / Number of People
```

Therefore:

```text
Total Age
= Average Age × Number of People
```

---

## 🔄 Replacement in Average

If one person of age `A` is replaced by a person of age `B`:

```text
New Total
= Old Total - A + B
```

If number of people = `N`:

```text
New Average
= Old Average + (B-A)/N
```

---

## 👨‍👦 Parent-Child

If parent is `D` years older than child:

```text
Parent Age - Child Age = D
```

This difference remains constant.

---

## ⏳ Time-Based Equations

### `n` years ago

```text
A - n
```

### `n` years later

```text
A + n
```

### Example

A's age after 5 years is twice B's age 5 years ago:

```text
A + 5 = 2(B - 5)
```

---

## 🔢 Three People's Ratio

If:

```text
A : B : C = a : b : c
```

Then:

```text
A = ax
B = bx
C = cx
```

### If total age is `S`

```text
x = S/(a+b+c)
```

---

## 🧮 Multiple Age Equations

If:

```text
A = B + D
```

and:

```text
A + B = S
```

Then:

```text
B + D + B = S
```

```text
B = (S-D)/2
```

```text
A = (S+D)/2
```

---

## 🎯 Quick Shortcuts

### Ratio + Sum

```text
One unit
= Sum / Sum of ratio parts
```

### Ratio + Difference

```text
One unit
= Difference / Difference of ratio parts
```

### Average

```text
Total = Average × Number
```

### Replacement

```text
New Total
= Old Total - Leaving Age + Joining Age
```

---

## 📋 When to Use What?

| Problem Type             | Method                        |
| ------------------------ | ----------------------------- |
| Present/past/future      | Add/subtract years            |
| Ratio of ages            | `ax, bx`                      |
| Ratio + sum              | Divide by sum of ratio        |
| Ratio + difference       | Divide by difference of ratio |
| Average age              | `Average × Number`            |
| Person replaced          | Adjust total                  |
| Parent-child             | Constant difference           |
| Multiple time conditions | Form equations                |
