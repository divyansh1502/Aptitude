## 1. Basic Concept

A boat can move:

* In still water
* Downstream
* Upstream

A stream has its own velocity.

When the boat moves in the same direction as the stream, the stream helps the boat.

When the boat moves against the stream, the stream opposes the boat.

```text
Boat + Stream → Downstream
Boat - Stream → Upstream
```

---

## 2. Important Terms

### Boat Speed

Speed of the boat in still water.

Let:

```text
B = Boat speed in still water
```

### Stream Speed

Speed at which the water flows.

Let:

```text
S = Stream speed
```

### Downstream

Boat moves **with** the stream.

### Upstream

Boat moves **against** the stream.

---

## 3. Downstream Speed

When the boat moves downstream, the stream helps the boat.

```text
Downstream Speed = Boat Speed + Stream Speed
```

In symbols:

```text
D = B + S
```

### Example

Boat speed = 20 km/h

Stream speed = 5 km/h

Therefore:

```text
D = 20 + 5
  = 25 km/h
```

---

## 4. Upstream Speed

When the boat moves upstream, the stream opposes the boat.

```text
Upstream Speed = Boat Speed - Stream Speed
```

In symbols:

```text
U = B - S
```

### Example

Boat speed = 20 km/h

Stream speed = 5 km/h

Therefore:

```text
U = 20 - 5
  = 15 km/h
```

### Memory Trick

```text
Downstream → ADD
Upstream   → SUBTRACT
```

---

## 5. Finding Boat Speed and Stream Speed

If downstream and upstream speeds are known:

```text
D = B + S
U = B - S
```

Add both equations:

```text
D + U = 2B
```

Therefore:

```text
Boat Speed = (D + U)/2
```

Subtract:

```text
D - U = 2S
```

Therefore:

```text
Stream Speed = (D - U)/2
```

### Example

Downstream speed = 30 km/h

Upstream speed = 18 km/h

Boat speed:

```text
B = (30 + 18)/2
  = 24 km/h
```

Stream speed:

```text
S = (30 - 18)/2
  = 6 km/h
```

---

## 6. Distance, Speed and Time

The standard formulas apply:

```text
Speed = Distance / Time

Distance = Speed × Time

Time = Distance / Speed
```

For boats:

```text
Downstream Time = Distance / Downstream Speed

Upstream Time = Distance / Upstream Speed
```

---

## 7. Downstream and Upstream Time

Suppose:

```text
Distance = 60 km
Boat speed = 20 km/h
Stream speed = 5 km/h
```

Downstream speed:

```text
20 + 5 = 25 km/h
```

Downstream time:

```text
60/25
= 2.4 hours
```

Upstream speed:

```text
20 - 5 = 15 km/h
```

Upstream time:

```text
60/15
= 4 hours
```

---

## 8. Equal Distance Problems

If the same distance is travelled downstream and upstream:

```text
D = Same distance
```

Then:

```text
Downstream Time = D/(B+S)

Upstream Time = D/(B-S)
```

Since upstream speed is lower:

```text
Upstream Time > Downstream Time
```

### Average Speed for Equal Distances

For equal distances:

```text
Average Speed = 2xy/(x+y)
```

where:

```text
x = downstream speed
y = upstream speed
```

Therefore:

```text
Average Speed
= 2(B+S)(B-S) / [(B+S)+(B-S)]
```

Simplifying:

```text
Average Speed = (B²-S²)/B
```

---

## 9. Equal Time Problems

If a boat travels downstream and upstream for equal amounts of time:

```text
Distance = Speed × Time
```

Therefore total distance:

```text
D = (B+S)t + (B-S)t
```

```text
D = 2Bt
```

Notice that the stream effect cancels out.

---

## 10. Round Trips

A round trip means:

```text
Start → Destination → Start
```

Usually one part is downstream and the other is upstream.

### Example

Distance each way = 40 km

Boat speed = 15 km/h

Stream = 5 km/h

Downstream:

```text
Speed = 20 km/h
Time = 40/20
     = 2 hours
```

Upstream:

```text
Speed = 10 km/h
Time = 40/10
     = 4 hours
```

Total time:

```text
2 + 4 = 6 hours
```

## 11. Still Water vs Stream

### Still Water

No stream:

```text
Speed = B
```

### Downstream

```text
Speed = B + S
```

### Upstream

```text
Speed = B - S
```

Think of the stream as a moving walkway:

```text
Same direction → Faster
Opposite direction → Slower
```

---

## 12. Speed Difference

The difference between downstream and upstream speeds is:

```text
D - U
= (B+S) - (B-S)
= 2S
```

Therefore:

```text
Stream Speed = (D-U)/2
```

Similarly:

```text
D + U = 2B
```

Therefore:

```text
Boat Speed = (D+U)/2
```

---

## 13. Finding Distance

If downstream speed and time are known:

```text
Distance = Downstream Speed × Downstream Time
```

If upstream speed and time are known:

```text
Distance = Upstream Speed × Upstream Time
```

### Example

Downstream speed = 24 km/h

Time = 2.5 hours

Distance:

```text
24 × 2.5
= 60 km
```

---

## 14. Finding Time Difference

For the same distance:

```text
Downstream Time = D/(B+S)

Upstream Time = D/(B-S)
```

Difference:

```text
Time Difference
= D/(B-S) - D/(B+S)
```

Taking LCM:

```text
= D[(B+S)-(B-S)] / (B²-S²)
```

Therefore:

```text
Time Difference = 2DS/(B²-S²)
```

---

## 15. Percentage Change in Speed

If stream speed increases, downstream speed increases while upstream speed decreases.

Example:

```text
Boat = 20 km/h
Stream = 5 km/h
```

Downstream:

```text
25 km/h
```

Upstream:

```text
15 km/h
```

If the stream speed becomes 10 km/h:

```text
Downstream = 30 km/h
Upstream = 10 km/h
```

The effect is not the same in both directions.

## 16. Mixed Boat Problems

### Case 1: Downstream and Upstream Speeds Given

Use:

```text
B = (D+U)/2

S = (D-U)/2
```

### Case 2: Boat and Stream Speeds Given

Use:

```text
Downstream = B+S

Upstream = B-S
```

### Case 3: Distance Given

Use:

```text
Time = Distance/Speed
```

### Case 4: Round Trip

Calculate both times separately.

```text
Total Time
= Downstream Time
+ Upstream Time
```

### Case 5: Equal Distance Average Speed

Use:

```text
Average Speed = 2DU/(D+U)
```

## 18. Common Traps

### Trap 1: Using Addition Upstream

Wrong:

```text
B + S
```

Correct:

```text
B - S
```

### Trap 2: Confusing Boat Speed with Downstream Speed

Boat speed means **speed in still water**.

It is not automatically the downstream speed.

### Trap 3: Forgetting Direction

Always identify:

```text
With stream → Downstream
Against stream → Upstream
```

### Trap 4: Using Arithmetic Mean for Equal Distance

For equal distances:

```text
(B1+B2)/2
```

is generally wrong.

Use:

```text
2B1B2/(B1+B2)
```

### Trap 5: Adding Round-Trip Speeds

Do not calculate round-trip time using:

```text
Distance / (D+U)
```

Calculate each journey separately.

### Trap 6: Ignoring Units

Convert:

```text
minutes → hours
meters → kilometers
```

before applying formulas.

## 19. Exam Strategy

When you see a Boats & Streams question:

1. Identify boat speed `B`.
2. Identify stream speed `S`.
3. Determine direction.
4. Calculate downstream/upstream speed.
5. Apply `D = ST`.
6. For a round trip, calculate both legs separately.
7. For equal distances, use harmonic mean for average speed.
8. Check units.

### Master Flow

```text
             BOATS & STREAMS
                    ↓
          Identify direction
             ↙           ↘
       Downstream       Upstream
           ↓                ↓
        B + S             B - S
             \             /
              \           /
               ↓         ↓
              Distance / Speed
                    ↓
                  Time
```

### Final Memory Trick

```text
Downstream = B + S
Upstream   = B - S

B = (D + U)/2
S = (D - U)/2

Distance = Speed × Time
Time = Distance / Speed

Equal Distance Average:
2DU/(D+U)
```
