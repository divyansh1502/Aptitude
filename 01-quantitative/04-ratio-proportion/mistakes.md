# Ratio & Proportion — Common Mistakes

## 1. Not Converting Units

### Mistake

Writing:

```text
2 kg : 500 g = 2 : 500
```

### Correct

Convert both into the same unit:

```text
2 kg = 2000 g

2000 : 500
= 4 : 1
```

### Fix

**Same units first, ratio second.**

---

## 2. Using the Wrong Total Parts

For:

```text
A : B = 3 : 5
```

total parts are:

```text
3 + 5 = 8
```

Not `5`, not `3`, and not `15`.

### Fix

For a total:

```text
Add all ratio terms.
```

---

## 3. Using the Wrong Difference

For:

```text
A : B = 3 : 7
```

the difference in parts is:

```text
7 - 3 = 4
```

Not `7`.

### Fix

For a given difference:

```text
Subtract the ratio terms.
```

---

## 4. Confusing Ratio with Percentage

If:

```text
A : B = 3 : 5
```

A is:

```text
3/5 × 100 = 60%
```

of B.

It is **not** `3%` or `5%`.

### Fix

Convert ratio to percentage using:

```text
First term / Second term × 100
```

when asked for the first quantity as a percentage of the second.

---

## 5. Reversing the Ratio

If:

```text
A : B = 2 : 5
```

then:

```text
B : A = 5 : 2
```

### Fix

Read the order carefully.

```text
A:B ≠ B:A
```

---

## 6. Treating Direct Proportion as Inverse

If more books are purchased, total cost increases.

That is direct proportion.

```text
More books → More cost
```

But:

```text
More workers → Fewer days
```

is inverse proportion.

### Fix

Ask:

> When one quantity increases, does the other increase or decrease?

---

## 7. Forgetting Cross Multiplication

For:

```text
a/b = c/d
```

the correct relationship is:

```text
a × d = b × c
```

### Fix

Multiply **diagonally**.

---

## 8. Combining Ratios Without Matching the Common Term

Given:

```text
A:B = 2:3
B:C = 4:5
```

You cannot simply write:

```text
A:B:C = 2:3:5
```

because the two values of B are different.

### Correct

Make B equal first:

```text
2:3 → 8:12
4:5 → 12:15
```

Therefore:

```text
A:B:C = 8:12:15
```

### Fix

**Match the common term before combining ratios.**

---

## 9. Assuming Equal Addition Preserves a Ratio

Suppose:

```text
A:B = 2:3
```

Add `10` to both.

You cannot assume:

```text
(A+10):(B+10) = 2:3
```

For example:

```text
20:30 = 2:3
```

After adding 10:

```text
30:40 = 3:4
```

The ratio changed.

### Fix

Recalculate the ratio after addition or subtraction.

---

## 10. Forgetting Capital × Time in Partnership

If partners invest different amounts for different periods, profit is not based only on capital.

Use:

```text
Profit Ratio = Capital × Time
```

### Fix

Calculate each partner's:

```text
Capital × Investment Time
```

then compare.

---

# Quick Revision Checklist

Before submitting a ratio/proportion answer, check:

```text
□ Are all units the same?
□ Did I simplify the ratio?
□ Did I add parts for a total question?
□ Did I subtract parts for a difference question?
□ Did I identify direct or inverse proportion?
□ Did I match common terms when combining ratios?
□ Did I cross multiply correctly?
□ Did I use the correct reference quantity?
□ Did I account for time in partnership questions?
```
