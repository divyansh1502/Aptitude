# Ratio & Proportion — Formulas

## 1. Basic Ratio

```text
a : b = a/b
```

Equivalent ratio:

```text
a : b = ka : kb
```

where `k ≠ 0`.

---

## 2. Simplifying Ratio

```text
a : b
= a/HCF : b/HCF
```

---

## 3. Ratio with Total

If:

```text
A : B = a : b
```

and total = `T`:

```text
A = a/(a+b) × T
```

```text
B = b/(a+b) × T
```

---

## 4. Ratio with Difference

If:

```text
A : B = a : b
```

and difference = `D`:

```text
One part = D/(b-a)
```

Then:

```text
A = a × One Part
B = b × One Part
```

---

## 5. Ratio with Known Quantity

If:

```text
A : B = a : b
```

and `A = X`:

```text
B = X × b/a
```

If `B = X`:

```text
A = X × a/b
```

---

## 6. Proportion

```text
a : b = c : d
```

Equivalent to:

```text
a/b = c/d
```

Cross multiplication:

```text
ad = bc
```

---

## 7. Fourth Proportional

If:

```text
a : b = c : x
```

then:

```text
x = bc/a
```

---

## 8. Third Proportional

If:

```text
a : b = b : x
```

then:

```text
x = b²/a
```

---

## 9. Mean Proportional

If:

```text
a : x = x : b
```

then:

```text
x² = ab
```

```text
x = √ab
```

---

## 10. Fraction Ratio

```text
a/b : c/d
= ad : bc
```

---

## 11. Direct Proportion

```text
A ∝ B
```

Therefore:

```text
A/B = constant
```

For two situations:

```text
A₁/B₁ = A₂/B₂
```

---

## 12. Inverse Proportion

```text
A ∝ 1/B
```

Therefore:

```text
AB = constant
```

For two situations:

```text
A₁B₁ = A₂B₂
```

---

## 13. Combining Ratios

If:

```text
A:B = a:b
B:C = c:d
```

Make the values of `B` equal, then combine.

---

## 14. Division in Ratio

To divide `T` in ratio:

```text
a : b
```

First part:

```text
a/(a+b) × T
```

Second part:

```text
b/(a+b) × T
```

---

## 15. Three-Part Ratio

If:

```text
A : B : C = a : b : c
```

and total = `T`:

```text
A = a/(a+b+c) × T
```

```text
B = b/(a+b+c) × T
```

```text
C = c/(a+b+c) × T
```

---

## 16. Ratio and Percentage

If:

```text
A:B = a:b
```

A as percentage of B:

```text
a/b × 100
```

B as percentage of A:

```text
b/a × 100
```

---

## 17. Partnership

```text
Profit Ratio = Capital × Time
```

For two partners:

```text
A:B = C₁T₁ : C₂T₂
```

---

## 18. Ratio of Fractions

```text
(a/b) : (c/d)
= ad : bc
```

---

## 19. Ratio of Decimals

Multiply both terms by a suitable power of `10`.

Example:

```text
0.4 : 0.8
= 4 : 8
= 1 : 2
```

---

## 20. Unit Conversion

Before forming a ratio:

```text
Convert both quantities into the same unit.
```

---

## 22. Quick Decision Table

| Question Type         | Formula / Method                    |
| --------------------- | ----------------------------------- |
| Simplify ratio        | Divide by HCF                       |
| Ratio + total         | Total ÷ sum of parts                |
| Ratio + difference    | Difference ÷ difference of parts    |
| Unknown in proportion | Cross multiply                      |
| Fourth proportional   | `bc/a`                              |
| Third proportional    | `b²/a`                              |
| Mean proportional     | `√ab`                               |
| Direct proportion     | `A/B = constant`                    |
| Inverse proportion    | `AB = constant`                     |
| Partnership           | `Capital × Time`                    |
| Divide quantity       | Ratio part / Total parts × quantity |
