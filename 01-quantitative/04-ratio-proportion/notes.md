# Ratio & Proportion — Notes

## 1. What is a Ratio?

A **ratio** compares two quantities of the same kind.

If there are `20` boys and `30` girls:

```text
Boys : Girls = 20 : 30
               = 2 : 3
```

So the ratio is:

```text
2 : 3
```

### Important

The quantities being compared should have the **same unit**.

Example:

```text
2 m : 50 cm
```

Convert first:

```text
2 m = 200 cm

Ratio = 200 : 50
      = 4 : 1
```

---

# 2. Ratio Notation

A ratio is written as:

```text
a : b
```

It can also be written as:

```text
a/b
```

The two numbers are called **terms**.

```text
a : b

a → first term
b → second term
```

---

# 3. Simplifying a Ratio

Divide both terms by their HCF.

### Example

Simplify:

```text
36 : 48
```

HCF of `36` and `48` is `12`.

```text
36 : 48
= 36/12 : 48/12
= 3 : 4
```

**Answer: `3 : 4`**

---

# 4. Equivalent Ratios

Multiplying or dividing both terms by the same non-zero number gives an equivalent ratio.

```text
2 : 3
```

Multiply by `4`:

```text
8 : 12
```

Both represent the same ratio.

```text
2 : 3 = 8 : 12
```

---

# 5. Ratio of More Than Two Quantities

A ratio can compare three or more quantities.

Example:

```text
A : B : C = 2 : 3 : 5
```

This means:

```text
A = 2x
B = 3x
C = 5x
```

for some common multiplier `x`.

---

# 6. Finding Quantities from a Given Ratio

Suppose:

```text
A : B = 3 : 5
```

and:

```text
A + B = 64
```

Total ratio parts:

```text
3 + 5 = 8
```

One part:

```text
64/8 = 8
```

Therefore:

```text
A = 3 × 8 = 24
B = 5 × 8 = 40
```

### Answer

```text
A = 24
B = 40
```

---

# 7. Ratio and Total

If:

```text
A : B = a : b
```

and total is `T`:

```text
A = a/(a+b) × T
```

```text
B = b/(a+b) × T
```

### Example

A : B = `2 : 3`

Total = `100`.

```text
A = 2/5 × 100 = 40

B = 3/5 × 100 = 60
```

---

# 8. Ratio and Difference

Suppose:

```text
A : B = 3 : 5
```

and their difference is `20`.

Difference in ratio parts:

```text
5 - 3 = 2
```

So:

```text
2 parts = 20
```

One part:

```text
20/2 = 10
```

Therefore:

```text
A = 3 × 10 = 30
B = 5 × 10 = 50
```

---

# 9. Ratio When One Quantity is Known

Suppose:

```text
A : B = 4 : 7
```

and:

```text
A = 28
```

Since:

```text
4 parts = 28
```

One part:

```text
28/4 = 7
```

Therefore:

```text
B = 7 × 7 = 49
```

**Answer: `49`**

---

# 10. Finding Ratio from Actual Values

If:

```text
A = 45
B = 75
```

then:

```text
A : B = 45 : 75
```

Divide by HCF `15`:

```text
= 3 : 5
```

---

# 11. Ratio of Fractions

To compare fractions:

```text
a/b : c/d
```

Multiply both by `bd`:

```text
ad : bc
```

### Example

Find:

```text
2/3 : 5/6
```

Multiply by `18`:

```text
12 : 15
= 4 : 5
```

**Answer: `4 : 5`**

---

# 12. Ratio of Decimals

Convert decimals into integers.

### Example

Find:

```text
0.6 : 1.2
```

Multiply both by `10`:

```text
6 : 12
= 1 : 2
```

**Answer: `1 : 2`**

---

# 13. Ratio with Different Units

Always convert to the same unit first.

### Example

Find:

```text
3 kg : 500 g
```

Convert:

```text
3 kg = 3000 g
```

Therefore:

```text
3000 : 500
= 6 : 1
```

**Answer: `6 : 1`**

---

# 14. What is Proportion?

A **proportion** states that two ratios are equal.

```text
a : b = c : d
```

or:

```text
a/b = c/d
```

This is written as:

```text
a : b :: c : d
```

Read it as:

> a is to b as c is to d.

---

# 15. Cross Multiplication

If:

```text
a/b = c/d
```

then:

```text
a × d = b × c
```

### Example

Find `x`:

```text
3 : 5 = x : 20
```

Cross multiply:

```text
3 × 20 = 5x

60 = 5x

x = 12
```

**Answer: `12`**

---

# 16. Fourth Proportional

If:

```text
a : b = c : x
```

then `x` is called the **fourth proportional**.

```text
x = (b × c)/a
```

### Example

Find the fourth proportional to `3, 5, 12`.

```text
3 : 5 = 12 : x
```

Therefore:

```text
3x = 60

x = 20
```

**Answer: `20`**

---

# 17. Third Proportional

If:

```text
a : b = b : x
```

then `x` is called the **third proportional**.

```text
x = b²/a
```

### Example

Find the third proportional to `4` and `8`.

```text
4 : 8 = 8 : x
```

Therefore:

```text
4x = 64

x = 16
```

**Answer: `16`**

---

# 18. Mean Proportional

If:

```text
a : x = x : b
```

then `x` is the **mean proportional** between `a` and `b`.

```text
x² = ab
```

Therefore:

```text
x = √ab
```

### Example

Find the mean proportional between `4` and `25`.

```text
x = √(4 × 25)
  = √100
  = 10
```

**Answer: `10`**

---

# 19. Direct Proportion

Two quantities are directly proportional when:

```text
A ∝ B
```

This means:

```text
A/B = constant
```

If one increases, the other also increases in the same proportion.

### Example

If `5` notebooks cost `₹100`, then `10` notebooks cost:

```text
5/100 = 10/x
```

Cross multiply:

```text
5x = 1000

x = 200
```

**Answer: `₹200`**

---

# 20. Inverse Proportion

Two quantities are inversely proportional when:

```text
A ∝ 1/B
```

Therefore:

```text
A × B = constant
```

If one increases, the other decreases.

### Example

If `5` workers complete a job in `12` days, how many days will `10` workers take?

```text
Workers × Days = Constant
```

```text
5 × 12 = 10 × x
```

```text
60 = 10x

x = 6
```

**Answer: `6 days`**

---

# 21. Direct vs Inverse Proportion

| Direct Proportion               | Inverse Proportion             |
| ------------------------------- | ------------------------------ |
| Both increase/decrease together | One increases, other decreases |
| `A/B = constant`                | `A × B = constant`             |
| More items → more cost          | More workers → fewer days      |
| More distance → more fuel       | More speed → less time         |

# 22. Combining Ratios

Suppose:

```text
A : B = 2 : 3
B : C = 4 : 5
```

The common term is `B`.

Make the value of `B` equal.

First ratio:

```text
A : B = 2 : 3
```

Second ratio:

```text
B : C = 4 : 5
```

LCM of `3` and `4` is `12`.

First ratio × `4`:

```text
A : B = 8 : 12
```

Second ratio × `3`:

```text
B : C = 12 : 15
```

Therefore:

```text
A : B : C = 8 : 12 : 15
```

---

# 23. Dividing a Quantity in a Given Ratio

Divide `₹900` between A and B in the ratio `4 : 5`.

Total parts:

```text
4 + 5 = 9
```

One part:

```text
900/9 = 100
```

Therefore:

```text
A = 4 × 100 = ₹400

B = 5 × 100 = ₹500
```

---

# 24. Ratio Changes When a Quantity Changes

Suppose:

```text
A : B = 3 : 5
```

A increases by `20%`.

Then:

```text
New A = 3 × 1.20
      = 3.6
```

B remains `5`.

New ratio:

```text
3.6 : 5
```

Multiply by `10`:

```text
36 : 50
= 18 : 25
```

---

# 25. Ratio and Percentage

If:

```text
A : B = 3 : 5
```

A as a percentage of B:

```text
3/5 × 100
= 60%
```

B is what percentage more than A?

```text
(5-3)/3 × 100
= 66⅔%
```

The reference quantity matters.

---

# 26. Age Ratio Problems

Suppose the present ages of A and B are in the ratio:

```text
3 : 5
```

and their total age is `40`.

Total parts:

```text
3 + 5 = 8
```

One part:

```text
40/8 = 5
```

Therefore:

```text
A = 15 years
B = 25 years
```

---

# 27. Age Ratio After Some Years

Suppose:

```text
A : B = 2 : 3
```

and their ages are:

```text
20 and 30
```

After `10` years:

```text
30 and 40
```

New ratio:

```text
30 : 40
= 3 : 4
```

### Important

When the **same number** is added to both quantities, the ratio generally changes.

---

# 28. Mixture Ratio

If two ingredients are mixed in the ratio:

```text
A : B = 2 : 3
```

then total parts:

```text
5
```

For `25 L` mixture:

```text
A = 2/5 × 25 = 10 L

B = 3/5 × 25 = 15 L
```

---

# 29. Partnership Ratio

When partners invest for different periods:

```text
Profit Ratio = Capital × Time
```

### Example

A invests `₹10,000` for `12` months.

B invests `₹20,000` for `6` months.

Their profit ratio:

```text
A : B
= 10,000 × 12 : 20,000 × 6
= 120,000 : 120,000
= 1 : 1
```

# 31. Common Traps

### Trap 1 — Different Units

Never compare:

```text
2 kg : 500 g
```

directly.

Convert first.

### Trap 2 — Wrong Reference

For:

```text
A : B = 3 : 5
```

A as a percentage of B:

```text
3/5 × 100
```

not:

```text
5/3 × 100
```

### Trap 3 — Direct vs Inverse

More workers usually mean fewer days for the same work.

That is inverse proportion.

### Trap 4 — Adding Ratios Directly

You cannot directly combine:

```text
A:B = 2:3
B:C = 4:5
```

The common term must first be made equal.

### Trap 5 — Ratio After Equal Addition

Adding the same number to both terms does **not** generally preserve the ratio.

---

# 32. Exam Strategy

When solving a ratio question:

### Step 1

Identify the quantities being compared.

### Step 2

Make units identical.

### Step 3

Simplify the ratio.

### Step 4

Look for:

```text
Total → Add ratio parts
Difference → Subtract ratio parts
One quantity → Find one part
Proportion → Cross multiply
Direct → Divide / constant ratio
Inverse → Product constant
```

### Step 5

Check whether the answer is logically reasonable.
