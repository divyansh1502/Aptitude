## 1. Basic Geometry

Geometry studies:

* Points
* Lines
* Angles
* Triangles
* Quadrilaterals
* Polygons
* Circles
* 2D figures
* 3D solids

### Point

A point represents an exact position.

### Line

A line extends infinitely in both directions.

### Line Segment

A part of a line with two endpoints.

### Ray

A part of a line with one endpoint and extending infinitely in one direction.

---

## 2. Lines and Angles

### Types of Angles

| Angle    |     Measure |
| -------- | ----------: |
| Acute    |     `< 90°` |
| Right    |       `90°` |
| Obtuse   |  `90°–180°` |
| Straight |      `180°` |
| Reflex   | `180°–360°` |
| Complete |      `360°` |

---

### Complementary Angles

Two angles whose sum is `90°`.

```text
A + B = 90°
```

Example:

If one angle is `35°`:

```text
Other = 90° - 35°
      = 55°
```

---

### Supplementary Angles

Two angles whose sum is `180°`.

```text
A + B = 180°
```

---

### Vertically Opposite Angles

When two lines intersect:

```text
Vertically opposite angles are equal.
```

---

### Linear Pair

Two adjacent angles forming a straight line:

```text
A + B = 180°
```

---

### Parallel Lines

When a transversal intersects parallel lines:

* Corresponding angles are equal.
* Alternate interior angles are equal.
* Co-interior angles sum to `180°`.

---

## 3. Triangles

A triangle has:

```text
3 sides
3 angles
```

### Angle Sum

```text
A + B + C = 180°
```

### Example

If two angles are `50°` and `60°`:

```text
Third angle
= 180° - 50° - 60°
= 70°
```

---

### Types by Sides

#### Equilateral

All three sides equal.

```text
a = a = a
```

Each angle:

```text
60°
```

#### Isosceles

Two sides equal.

The angles opposite those equal sides are also equal.

#### Scalene

All three sides are different.

---

### Types by Angles

#### Acute Triangle

All angles `< 90°`.

#### Right Triangle

One angle = `90°`.

#### Obtuse Triangle

One angle `> 90°`.

---

## 4. Important Triangle Properties

### Pythagoras Theorem

For a right triangle:

```text
Hypotenuse² = Base² + Perpendicular²
```

or:

```text
c² = a² + b²
```

### Example

If:

```text
a = 3
b = 4
```

then:

```text
c² = 3² + 4²
   = 9 + 16
   = 25
```

```text
c = 5
```

So:

```text
3-4-5
```

is a common Pythagorean triple.

Other useful triples:

```text
5-12-13
7-24-25
8-15-17
9-40-41
```

---

### Exterior Angle

An exterior angle of a triangle equals the sum of the two opposite interior angles.

```text
Exterior angle
= Opposite interior angle 1
+ Opposite interior angle 2
```

---

### Triangle Inequality

For sides `a`, `b`, `c`:

```text
a + b > c
a + c > b
b + c > a
```

---

## 5. Quadrilaterals

A quadrilateral has:

```text
4 sides
```

Sum of interior angles:

```text
360°
```

---

### Square

All sides equal and all angles `90°`.

```text
Area = a²
Perimeter = 4a
Diagonal = a√2
```

---

### Rectangle

Opposite sides equal.

```text
Area = l×b
Perimeter = 2(l+b)
Diagonal = √(l²+b²)
```

---

### Parallelogram

Opposite sides are equal and parallel.

```text
Area = Base × Height
```

---

### Rhombus

All sides equal.

```text
Area = 1/2 × d₁ × d₂
```

---

### Trapezium

One pair of opposite sides is parallel.

If parallel sides are `a` and `b`:

```text
Area = 1/2 × (a+b) × h
```

---

## 6. Polygons

A polygon is a closed figure made of straight line segments.

### Interior Angle Sum

For an `n`-sided polygon:

```text
(n-2) × 180°
```

### Example

Pentagon:

```text
(5-2)×180°
= 540°
```

---

### Each Interior Angle of a Regular Polygon

```text
[(n-2)×180°]/n
```

---

### Exterior Angle Sum

For any convex polygon:

```text
360°
```

For a regular polygon:

```text
Each exterior angle = 360°/n
```

---

### Number of Diagonals

For an `n`-sided polygon:

```text
n(n-3)/2
```

Example:

Hexagon:

```text
6(6-3)/2
= 9
```

* Centre

* Tangent
* Circumference

### Radius and Diameter

```text
d = 2r
```

```text
r = d/2
```

---

### Circumference

```text
C = 2πr
```

or:

```text
C = πd
```

---

### Area

```text
A = πr²
```

---

### Semicircle

Area:

```text
1/2 πr²
```

Curved perimeter:

```text
πr
```

Total perimeter of semicircle:

```text
πr + 2r
```

---

### Quadrant

A quadrant is one-fourth of a circle.

Area:

```text
πr²/4
```

Arc length:

```text
πr/2
```

---

### Sector

For angle `θ`:

Area:

```text
θ/360 × πr²
```

Arc length:

```text
θ/360 × 2πr
```

```text
((x₁+x₂)/2, (y₁+y₂)/2)
```

## 10. Area of 2D Figures

### Square

```text
a²
```

### Rectangle

```text
l×b
```

### Triangle

```text
1/2 × base × height
```

### Parallelogram

```text
base × height
```

### Rhombus

```text
1/2 × d₁ × d₂
```

### Trapezium

```text
1/2 × (a+b) × h
```

### Circle

```text
πr²
```

---

### Composite Figures

For irregular/composite figures:

1. Divide the figure into known shapes.
2. Calculate each area.
3. Add/subtract as required.

Example:

```text
Total Area
= Rectangle Area + Semicircle Area
```

## 11. Heron's Formula

For a triangle with sides `a`, `b`, `c`:

First calculate semi-perimeter:

```text
s = (a+b+c)/2
```

Then:

```text
Area = √[s(s-a)(s-b)(s-c)]
```

### Example

Sides:

```text
3, 4, 5
```

Semi-perimeter:

```text
s = (3+4+5)/2
  = 6
```

Area:

```text
√[6×3×2×1]
= √36
= 6
```

## 13. Cube and Cuboid

### Cube

Side = `a`

Volume:

```text
a³
```

Total surface area:

```text
6a²
```

Lateral surface area:

```text
4a²
```

Space diagonal:

```text
a√3
```

---

### Cuboid

Dimensions:

```text
l, b, h
```

Volume:

```text
lbh
```

Total surface area:

```text
2(lb + bh + hl)
```

Lateral surface area:

```text
2h(l+b)
```

Diagonal:

```text
√(l²+b²+h²)
```

## 17. Unit Conversion

### Length

```text
1 m = 100 cm
1 km = 1000 m
```

### Area

When converting area, square the conversion factor:

```text
1 m² = 10,000 cm²
```

### Volume

Cube the conversion factor:

```text
1 m³ = 1,000,000 cm³
```

### Important

```text
Length → ×100
Area   → ×100²
Volume → ×100³
```

when converting metres to centimetres.

## 18. Common Patterns

### Pattern 1 — Find Missing Side

Use Pythagoras for right triangles.

```text
c² = a²+b²
```

---

### Pattern 2 — Find Area

Identify the shape first.

```text
Triangle → 1/2 bh
Circle   → πr²
Rectangle → lb
```

---

### Pattern 3 — Find Perimeter

Add all outer boundaries.

---

### Pattern 4 — Similar Scaling

If every length is multiplied by `k`:

```text
Length → k times
Area   → k² times
Volume → k³ times
```

Example:

If side doubles:

```text
Area   → 4 times
Volume → 8 times
```

---

### Pattern 5 — Inscribed/Circumscribed Shapes

Look for relationships between:

* Radius
* Diameter
* Side
* Diagonal

---

### Pattern 6 — Painting/Cost Problems

Usually:

```text
Cost = Area × Rate
```

For 3D painting:

```text
Cost = Surface Area × Rate
```

---

### Pattern 7 — Filling a Tank

Use volume.

```text
Volume = Capacity
```

Then:

```text
Time = Volume / Filling Rate
```

---

### Pattern 8 — Melting and Recasting

Volume is conserved:

```text
Original Volume = Final Volume
```

## 19. Common Traps

### Trap 1: Diameter vs Radius

If:

```text
d = 14
```

then:

```text
r = 7
```

Do not use `14` directly in `πr²`.

---

### Trap 2: Area vs Perimeter

```text
Area → square units
Perimeter → linear units
```

---

### Trap 3: Surface Area vs Volume

```text
Surface area → units²
Volume → units³
```

---

### Trap 4: Using Diameter in Radius Formula

Circle area:

```text
πr²
```

not:

```text
πd²
```

---

### Trap 5: Forgetting Both Sides of a Rectangle

Perimeter:

```text
2(l+b)
```

not:

```text
l+b
```

---

### Trap 6: Using Slant Height as Cone Height

For a cone:

```text
l² = r²+h²
```

Slant height and vertical height are different.

---

### Trap 7: Incorrect Unit Conversion

Remember:

```text
Length → square once
Area → square conversion
Volume → cube conversion
```

---

### Trap 8: Using `1/2 bh` Without a Perpendicular Height

The height in triangle area must be perpendicular to the selected base.

## 20. Exam Strategy

### Step 1

Identify the shape.

### Step 2

Write the required quantity:

```text
Perimeter?
Area?
Surface Area?
Volume?
Angle?
Length?
```

### Step 3

Convert all units to the same system.

### Step 4

Write the formula before substituting values.

### Step 5

Use suitable `π`:

```text
π = 22/7
```

when convenient, otherwise:

```text
π ≈ 3.14
```

### Step 6

Check the unit of the answer.

```text
Length      → units
Area        → units²
Volume      → units³
```
