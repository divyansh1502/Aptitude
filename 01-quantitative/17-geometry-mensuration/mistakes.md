# Geometry & Mensuration — Common Mistakes

> **Track these mistakes carefully. Geometry questions are usually easy conceptually, but small formula, unit, and interpretation errors can cost marks.**

---

## 1. Confusing Radius and Diameter

### Mistake

Using the diameter directly in:

```text
Area = πr²
```

### Example

If diameter = `14 cm`:

```text
r = 14/2
  = 7 cm
```

Then:

```text
Area = π×7²
```

### Why It Happens

Radius and diameter are often given interchangeably in questions.

### How to Avoid

Always write:

```text
d = 2r
r = d/2
```

before using the formula.

**Tag:** `C`

---

## 2. Confusing Area and Perimeter

### Mistake

Using perimeter when the question asks for area, or vice versa.

### Remember

```text
Perimeter → boundary
Area      → inside region
```

For a rectangle:

```text
Perimeter = 2(l+b)

Area = l×b
```

### How to Avoid

Look for words such as:

* boundary
* fencing
* wire
* perimeter

versus:

* floor
* field
* land
* painting
* surface

**Tag:** `C`

---

## 3. Forgetting the Correct Units

### Mistake

Writing:

```text
Area = 120 cm
```

instead of:

```text
Area = 120 cm²
```

### Correct Units

```text
Length       → cm, m, km
Area         → cm², m², km²
Volume       → cm³, m³
```

### How to Avoid

Check the unit before submitting the answer.

**Tag:** `S`

---

## 4. Incorrect Area Scaling

### Mistake

Thinking that if the side doubles, the area also doubles.

### Correct

If:

```text
New side = 2a
```

then:

```text
New area = (2a)²
         = 4a²
```

So:

```text
Side → 2 times
Area → 4 times
Volume → 8 times
```

### General Rule

If every length changes by a factor `k`:

```text
Length → k
Area   → k²
Volume → k³
```

**Tag:** `C`

---

## 5. Using the Wrong Height in a Triangle

### Mistake

Using a slanted side as the height in:

```text
Area = 1/2 × base × height
```

### Important

The height must be **perpendicular** to the selected base.

```text
        /\
       /  \
      / |  \
     /  |  \
    /___|___\
       ↑
   perpendicular
     height
```

### How to Avoid

Look for the `90°` relationship between base and height.

**Tag:** `C`

---

## 6. Forgetting the `1/2` in Triangle Area

### Mistake

Calculating:

```text
Area = base × height
```

### Correct

```text
Area = 1/2 × base × height
```

### Example

Base = `10`, height = `6`:

```text
Area = 1/2×10×6
     = 30
```

not `60`.

**Tag:** `S`

---

## 7. Confusing Cone Height and Slant Height

A cone has two different heights:

```text
h = vertical height
l = slant height
```

They are related by:

```text
l² = r²+h²
```

### Common Mistake

Using `l` instead of `h` in:

```text
Volume = 1/3πr²h
```

### Remember

```text
Volume → vertical height h

Curved Surface Area → slant height l
```

**Tag:** `C`

---

## 8. Incorrect Unit Conversion for Area and Volume

### Mistake

Using the same conversion factor for length, area, and volume.

For example:

```text
1 m = 100 cm
```

does **not** mean:

```text
1 m² = 100 cm²
```

### Correct

```text
1 m      = 100 cm
1 m²     = 10,000 cm²
1 m³     = 1,000,000 cm³
```

### Memory Trick

```text
Length → square once
Area   → square conversion
Volume → cube conversion
```

**Tag:** `C`

---

## 9. Forgetting Both Sides in Perimeter

### Mistake

For a rectangle:

```text
Perimeter = l+b
```

### Correct

There are two lengths and two breadths:

```text
Perimeter = 2(l+b)
```

### Example

For `l=10`, `b=5`:

```text
P = 2(10+5)
  = 30
```

not `15`.

**Tag:** `S`

---

## 10. Using the Wrong Surface Area of a Solid

Different questions may ask for:

* Curved Surface Area
* Lateral Surface Area
* Total Surface Area

For a cylinder:

```text
CSA = 2πrh

TSA = 2πr(h+r)
```

For a hemisphere:

```text
CSA = 2πr²

TSA = 3πr²
```

### How to Avoid

Read exactly what the question asks:

```text
Curved → only curved portion
Total  → curved + required flat surfaces
```

**Tag:** `R`

# 🧠 Quick Mistake Checklist

Before submitting a Geometry/Mensuration answer, check:

```text
□ Did I use radius instead of diameter where required?
□ Did I distinguish area from perimeter?
□ Did I use the correct unit?
□ Did I convert all units first?
□ Did I use perpendicular height?
□ Did I include 1/2 for triangle area?
□ Did I distinguish cone height and slant height?
□ Did I use the correct surface area?
□ Did I check whether the question asks total or curved surface?
□ Did I verify the final calculation?
```

# 🎯 Fast Memory Rules

```text
Radius = Diameter/2

Triangle Area = 1/2 bh

Circle Area = πr²

Circle Circumference = 2πr

Right Triangle = a²+b²=c²

Polygon Interior Sum = (n-2)180°

Cube Volume = a³

Cuboid Volume = lbh

Cylinder Volume = πr²h

Cone Volume = 1/3πr²h

Sphere Volume = 4/3πr³

Side × k → Area × k² → Volume × k³
```
