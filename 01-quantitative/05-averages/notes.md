# Average — Notes

## 1. What is an Average?

The **average** represents the equal share of the total among all observations.

```text
Average = Sum of all observations / Number of observations
```

### Example

Find the average of `10, 20, 30`.

```text
Sum = 10 + 20 + 30
    = 60

Number of values = 3

Average = 60/3
        = 20
```

**Answer: `20`**

---

# 2. Basic Formula

If there are `n` observations:

```text
Average = Sum / n
```

Therefore:

```text
Sum = Average × Number of observations
```

This second formula is extremely important in placement questions.

---

# 3. Finding the Sum from the Average

If the average of `8` numbers is `25`, their total sum is:

```text
Sum = Average × Number
    = 25 × 8
    = 200
```

**Answer: `200`**

---

# 4. Finding a Missing Number

Suppose the average of `5` numbers is `24`, and four numbers are:

```text
12, 20, 25, 30
```

Find the fifth number.

### Step 1: Find total required

```text
Total = 24 × 5
      = 120
```

### Step 2: Find known sum

```text
12 + 20 + 25 + 30 = 87
```

### Step 3: Find missing number

```text
120 - 87 = 33
```

**Answer: `33`**

---

# 5. Average of Two Numbers

For two numbers `a` and `b`:

```text
Average = (a+b)/2
```

### Example

Average of `36` and `54`:

```text
(36 + 54)/2
= 90/2
= 45
```

**Answer: `45`**

---

# 6. Average of Three or More Numbers

Add all numbers and divide by the number of observations.

### Example

Find the average of:

```text
15, 25, 35, 45, 55
```

```text
Sum = 15 + 25 + 35 + 45 + 55
    = 175

Average = 175/5
        = 35
```

**Answer: `35`**

---

# 7. Average When a New Number is Added

Suppose the average of `5` numbers is `20`.

Their total is:

```text
20 × 5 = 100
```

Now `30` is added.

New total:

```text
100 + 30 = 130
```

New number of observations:

```text
6
```

New average:

```text
130/6
= 21⅔
```

**Answer: `21⅔`**

### Important

Never simply average the old average and new number unless there are only equal-sized groups.

---

# 8. Average When a Number is Removed

Suppose the average of `6` numbers is `25`.

Total:

```text
25 × 6 = 150
```

If one number, `40`, is removed:

```text
New total = 150 - 40
          = 110
```

Remaining numbers:

```text
6 - 1 = 5
```

New average:

```text
110/5
= 22
```

**Answer: `22`**

---

# 9. Adding a Number to Increase the Average

Suppose the average of `5` numbers is `20`.

A number `40` is added.

Old total:

```text
20 × 5 = 100
```

New total:

```text
100 + 40 = 140
```

New average:

```text
140/6
= 23⅓
```

So the average increases by:

```text
23⅓ - 20
= 3⅓
```

---

# 10. Removing a Number to Change the Average

Suppose the average of `8` numbers is `30`.

One number is removed and the average becomes `28`.

Old total:

```text
30 × 8 = 240
```

New total:

```text
28 × 7 = 196
```

Removed number:

```text
240 - 196 = 44
```

**Answer: `44`**

---

# 11. Adding a Number When New Average is Given

Suppose the average of `10` numbers is `25`.

One new number is added and the average becomes `27`.

Old total:

```text
25 × 10 = 250
```

New total:

```text
27 × 11 = 297
```

New number:

```text
297 - 250 = 47
```

**Answer: `47`**

---

# 12. Replacement of a Number

A common placement pattern:

> The average of `8` numbers is `24`. One number `18` is replaced by `34`. Find the new average.

Old total:

```text
24 × 8 = 192
```

Increase in total:

```text
34 - 18 = 16
```

New total:

```text
192 + 16 = 208
```

New average:

```text
208/8 = 26
```

**Answer: `26`**

### Shortcut

If one value changes from `a` to `b`:

```text
Change in average = (b-a)/n
```

---

# 13. Average Increase After Replacement

If one number is replaced by a number `d` units greater and there are `n` observations:

```text
Increase in average = d/n
```

### Example

In a group of `20` students, one student's marks increase by `10`.

Increase in average:

```text
10/20
= 0.5
```

**Average increases by `0.5 marks`.**

---

# 14. Combined Average

When two groups have different sizes, do **not** simply average their averages.

Suppose:

* Group A: `20` students, average `60`
* Group B: `30` students, average `70`

Total marks of A:

```text
20 × 60 = 1200
```

Total marks of B:

```text
30 × 70 = 2100
```

Combined total:

```text
1200 + 2100 = 3300
```

Total students:

```text
20 + 30 = 50
```

Combined average:

```text
3300/50
= 66
```

**Answer: `66`**

---

# 15. Combined Average Formula

For two groups:

```text
Group 1:
n₁ observations
average = A₁

Group 2:
n₂ observations
average = A₂
```

Combined average:

```text
Combined Average
= (n₁A₁ + n₂A₂)/(n₁+n₂)
```

### Key Rule

The group sizes matter.

---

# 16. Weighted Average

When different values have different weights:

```text
Weighted Average
= Σ(value × weight) / Σ(weight)
```

### Example

A student gets:

* `80` marks with weight `2`
* `60` marks with weight `3`

Weighted average:

```text
(80×2 + 60×3)/(2+3)

= (160 + 180)/5

= 340/5

= 68
```

**Answer: `68`**

---

# 17. Average of Consecutive Numbers

For consecutive numbers:

```text
n, n+1, n+2, ..., n+k
```

the average is the middle value when the number of terms is odd.

### Example

Average of:

```text
21, 22, 23, 24, 25
```

The middle number is `23`.

**Answer: `23`**

---

# 18. Average of Consecutive Even Numbers

Example:

```text
12, 14, 16, 18, 20
```

The middle number is:

```text
16
```

Therefore average = `16`.

### Shortcut

For an odd number of equally spaced terms:

```text
Average = Middle term
```

---

# 19. Average of Consecutive Odd Numbers

Example:

```text
11, 13, 15, 17, 19
```

Middle term:

```text
15
```

Therefore:

```text
Average = 15
```

---

# 20. Average of Equally Spaced Numbers

For numbers such as:

```text
10, 15, 20, 25, 30
```

average:

```text
(First + Last)/2
```

```text
(10 + 30)/2
= 20
```

This works for an arithmetic sequence/equally spaced values.

---

# 21. Average of First n Natural Numbers

For:

```text
1, 2, 3, ..., n
```

Average:

```text
(n+1)/2
```

### Example

Average of first `20` natural numbers:

```text
(20+1)/2
= 10.5
```

---

# 22. Average of First n Odd Numbers

The average of the first `n` odd numbers is:

```text
n
```

### Example

First `5` odd numbers:

```text
1, 3, 5, 7, 9
```

Average:

```text
25/5 = 5
```

---

# 23. Average of First n Even Numbers

First `n` even numbers are:

```text
2, 4, 6, ..., 2n
```

Average:

```text
n + 1
```

### Example

First `10` even numbers:

```text
Average = 10 + 1
        = 11
```

# 24. Average Age Problems

The same average formula applies to ages.

### Example

The average age of `5` people is `24`.

Total age:

```text
24 × 5 = 120
```

If a new person aged `30` joins:

```text
New total = 120 + 30
          = 150
```

Number of people:

```text
6
```

New average:

```text
150/6 = 25
```

**Answer: `25 years`**

---

# 25. Average Speed — Important Distinction

Average speed is:

```text
Average Speed = Total Distance / Total Time
```

It is **not always** the simple average of speeds.

For equal distances travelled at speeds `a` and `b`:

```text
Average Speed = 2ab/(a+b)
```

### Example

A vehicle travels equal distances at `40 km/h` and `60 km/h`.

Average speed:

```text
2×40×60/(40+60)

= 4800/100

= 48 km/h
```

**Answer: `48 km/h`**

# 28. Average with One Group Removed

Suppose the average marks of `50` students is `60`.

The average marks of `20` students is `70`.

Find the average of the remaining `30` students.

Total marks of all:

```text
50 × 60 = 3000
```

Marks of 20 students:

```text
20 × 70 = 1400
```

Remaining marks:

```text
3000 - 1400 = 1600
```

Remaining students:

```text
50 - 20 = 30
```

Average:

```text
1600/30
= 53⅓
```

**Answer: `53⅓`**

# 29. Average and Deviation

A useful shortcut:

If the average is `A`, and each value differs from `A` by some amount:

```text
Average
= A + (Sum of deviations / Number of values)
```

If the sum of deviations from `A` is zero:

```text
Average = A
```

### Example

Consider:

```text
48, 49, 50, 51, 52
```

Take assumed average `50`.

Deviations:

```text
-2, -1, 0, +1, +2
```

Sum:

```text
0
```

Therefore average = `50`.

---

# 30. Assumed Average Method

For large values, choose an assumed average `A`.

Calculate deviations:

```text
d = Actual value - A
```

Then:

```text
Actual Average
= A + Σd/n
```

### Example

Find the average of:

```text
98, 102, 105, 95, 100
```

Take assumed average `100`.

Deviations:

```text
-2, +2, +5, -5, 0
```

Sum:

```text
0
```

Therefore:

```text
Average = 100
```

# 31. Average of Two Groups with Known Combined Average

Suppose:

* Group A has `20` people with average `40`
* Group B has `30` people
* Combined average is `46`

Find the average of Group B.

Total combined:

```text
50 × 46 = 2300
```

Group A total:

```text
20 × 40 = 800
```

Group B total:

```text
2300 - 800 = 1500
```

Group B average:

```text
1500/30 = 50
```

**Answer: `50`**

# 32. Important Average Properties

### Property 1

If every value increases by `k`, average also increases by `k`.

Example:

```text
10, 20, 30
Average = 20
```

Add `5` to every value:

```text
15, 25, 35
Average = 25
```

---

### Property 2

If every value decreases by `k`, average decreases by `k`.

---

### Property 3

If every value is multiplied by `k`, average is also multiplied by `k`.

---

### Property 4

If every value is divided by `k`, average is also divided by `k`.

# 34. Common Traps

### Trap 1 — Averaging Averages Directly

If groups have different sizes:

```text
(60 + 70)/2
```

is generally wrong.

Use weighted/combined average.

---

### Trap 2 — Forgetting the Number of Observations

Always identify:

```text
Number of values = n
```

before using:

```text
Sum = Average × n
```

---

### Trap 3 — Replacement

When one value is replaced, the number of observations stays the same.

Only the total changes.

---

### Trap 4 — Average Speed

Average speed is:

```text
Total Distance / Total Time
```

not automatically:

```text
(Speed 1 + Speed 2)/2
```

---

### Trap 5 — New Number Added

The denominator also changes.

If there were `n` values and one is added:

```text
New count = n + 1
```

---

# 35. Exam Strategy

When you see an average question:

### Step 1

Identify the number of observations.

### Step 2

Convert average into total:

```text
Total = Average × Count
```

### Step 3

Add/remove/replace the required values.

### Step 4

Divide by the new count.

### Step 5

For groups, calculate each group's total separately.

### Quick Memory

```text
AVERAGE
   ↓
TOTAL / COUNT
   ↓
TOTAL = AVERAGE × COUNT
```

Most placement questions become easy once you find the **total**.
