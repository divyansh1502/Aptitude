# 05-averages - Formulas and Shortcuts

# Average — Formulas

## 1. Basic Average

```text
Average = Sum / Number of observations
```

---

## 2. Finding Total

```text
Sum = Average × Number of observations
```

---

## 3. Finding Number of Observations

```text
Number of observations = Sum / Average
```

---

## 4. Missing Value

```text
Missing value
= Required total - Sum of known values
```

where:

```text
Required total = Average × Number of values
```

---

## 5. Average of Two Numbers

```text
Average = (a+b)/2
```

---

## 6. Combined Average

For two groups:

```text
Combined Average
= (n₁A₁ + n₂A₂)/(n₁+n₂)
```

---

## 7. Weighted Average

```text
Weighted Average
= Σ(value × weight) / Σ(weight)
```

---

## 8. New Average After Adding One Value

Old average = `A`
Old count = `n`
New value = `x`

```text
New Average = (nA+x)/(n+1)
```

---

## 9. New Average After Removing One Value

Old average = `A`
Old count = `n`
Removed value = `x`

```text
New Average = (nA-x)/(n-1)
```

---

## 10. Value Added to Change Average

Old average = `A`
New average = `B`
Old count = `n`

New value:

```text
New value = (n+1)B - nA
```

---

## 11. Value Removed to Change Average

Old average = `A`
New average = `B`
Old count = `n`

Removed value:

```text
Removed value = nA - (n-1)B
```

---

## 12. Replacement

Old average = `A`
Count = `n`
Old value = `x`
New value = `y`

```text
New Average
= A + (y-x)/n
```

---

## 13. Change in Average After Replacement

```text
Change in Average = (New value - Old value)/n
```

---

## 14. Every Value Increased by `k`

```text
New Average = Old Average + k
```

---

## 15. Every Value Decreased by `k`

```text
New Average = Old Average - k
```

---

## 16. Every Value Multiplied by `k`

```text
New Average = k × Old Average
```

---

## 17. Every Value Divided by `k`

```text
New Average = Old Average/k
```

---

## 18. Consecutive Numbers

For equally spaced numbers:

```text
Average = (First + Last)/2
```

If there is an odd number of equally spaced terms:

```text
Average = Middle term
```

---

## 19. First `n` Natural Numbers

```text
Average = (n+1)/2
```

---

## 20. First `n` Odd Numbers

```text
Average = n
```

---

## 21. First `n` Even Numbers

```text
Average = n+1
```

---

## 22. Average Using Deviations

If assumed average = `A`:

```text
Actual Average
= A + Σd/n
```

where:

```text
d = Actual value - A
```

---

## 23. Average Speed

```text
Average Speed
= Total Distance / Total Time
```

For equal distances at speeds `a` and `b`:

```text
Average Speed = 2ab/(a+b)
```

---

## 24. Group Removal

If total group has:

```text
n₁ = total number
A₁ = total average
```

and removed group has:

```text
n₂ = removed number
A₂ = removed average
```

Remaining average:

```text
Remaining Average
= (n₁A₁ - n₂A₂)/(n₁-n₂)
```

---

## 25. Group Addition

If two groups are combined:

```text
Total = n₁A₁ + n₂A₂
```

```text
Count = n₁+n₂
```

Therefore:

```text
Combined Average
= Total/Count
```
