# Average — Common Mistakes

## 1. Forgetting the Basic Relationship

### Mistake

Trying to solve every average question by adding everything manually.

### Correct

Remember:

```text
Sum = Average × Number of values
```

This is usually the fastest starting point.

### Fix

Whenever an average is given, immediately think:

```text
AVERAGE → TOTAL
```

---

## 2. Dividing by the Wrong Number

Suppose there are `8` values.

The average is:

```text
Sum/8
```

not:

```text
Sum/7
```

### Fix

Count the observations carefully before dividing.

---

## 3. Averaging Two Averages Directly

Suppose:

* 10 students have average `50`
* 30 students have average `70`

Incorrect:

```text
(50 + 70)/2 = 60
```

### Correct

Use group sizes:

```text
(10×50 + 30×70)/(10+30)
= 65
```

### Fix

Different group sizes → **weighted average**.

---

## 4. Forgetting to Change the Count

If there are `10` values and one value is added:

```text
New count = 11
```

Not `10`.

### Fix

After adding/removing values, always update the denominator.

---

## 5. Forgetting That Replacement Keeps the Count Same

If one value is replaced:

```text
Old count = New count
```

Only the total changes.

### Fix

Use:

```text
New Average
= Old Average + (New value - Old value)/n
```

---

## 6. Using Simple Average for Average Speed

A vehicle travels equal distances at `40 km/h` and `60 km/h`.

Incorrect:

```text
(40 + 60)/2 = 50 km/h
```

Correct:

```text
2×40×60/(40+60)
= 48 km/h
```

### Fix

For speed questions, start with:

```text
Average Speed = Total Distance / Total Time
```

---

## 7. Assuming the Average Must Be One of the Values

The average does not have to be an existing observation.

Example:

```text
10, 20
```

Average:

```text
15
```

`15` was not one of the original values.

### Fix

Average represents the equal-share value, not necessarily an existing value.

---

## 8. Missing the Middle-Term Shortcut

For equally spaced numbers:

```text
20, 25, 30, 35, 40
```

the average is simply:

```text
30
```

### Fix

For equally spaced values:

```text
Average = (First + Last)/2
```

or, with an odd number of terms:

```text
Average = Middle term
```

---

## 9. Forgetting Group Totals

Suppose:

* 20 people have average 50
* 30 people have average 60

Do not combine the averages first.

Calculate:

```text
20 × 50
30 × 60
```

Then combine the totals.

### Fix

Think:

```text
Group Average → Group Total
```

---

## 10. Ignoring the Reference Count in Replacement Questions

Suppose one value increases by `20` in a group of `10`.

The average does **not** increase by `20`.

It increases by:

```text
20/10 = 2
```

### Fix

For replacement:

```text
Change in average
= Change in value / Number of observations
```

---

# Quick Revision Checklist

Before submitting an average answer, check:

```text
□ Did I identify the number of observations?
□ Did I convert average into total when needed?
□ Did I use the correct new count?
□ If a value was removed, did I subtract it?
□ If a value was added, did I add it?
□ If a value was replaced, did I keep the count unchanged?
□ If groups have different sizes, did I use a weighted average?
□ If it is an equally spaced sequence, did I use the shortcut?
□ If it is average speed, did I use total distance / total time?
□ Did I check whether the answer is logically reasonable?
```
