## 🟢 Part A — Representative Questions

### Q1. AP nth Term

Find the 15th term of:

```text
4, 7, 10, 13, ...
```

**Solution**

```text
a = 4
d = 3
n = 15
```

```text
aₙ = a+(n-1)d
   = 4+14×3
   = 46
```

**Answer: 46**

---

### Q2. AP Sum

Find the sum of the first 20 terms of:

```text
3, 7, 11, 15, ...
```

**Solution**

```text
a = 3
d = 4
n = 20
```

```text
Sₙ = n/2[2a+(n-1)d]
```

```text
S₂₀ = 20/2[6+19×4]
     = 10[6+76]
     = 820
```

**Answer: 820**

---

### Q3. Missing Term in AP

Find `x` if:

```text
11, x, 23
```

are consecutive terms of an AP.

**Solution**

For three consecutive AP terms:

```text
2x = First + Third
```

```text
2x = 11+23
2x = 34
x = 17
```

**Answer: 17**

### Q5. Infinite GP

Find:

```text
8 + 4 + 2 + 1 + ...
```

**Solution**

```text
a = 8
r = 1/2
```

Since:

```text
|r| < 1
```

we can use:

```text
S∞ = a/(1-r)
```

```text
S∞ = 8/(1-1/2)
    = 8/(1/2)
    = 16
```

**Answer: 16**
