# Algebra — Notes

## 1. What is Algebra?

Algebra is the use of **variables, constants, and mathematical operations** to represent unknown quantities and solve problems.

Example:

```text
x + 5 = 12
```

Here:

* `x` → variable
* `5` and `12` → constants
* `=` → equality

Therefore:

```text
x = 7
```

---

# 2. Basic Algebraic Terms

Consider:

```text
3x² + 5x - 7
```

| Term  | Meaning             |
| ----- | ------------------- |
| `3`   | Coefficient of `x²` |
| `x`   | Variable            |
| `3x²` | Term                |
| `5x`  | Term                |
| `-7`  | Constant            |
| `2`   | Power/exponent      |

---

# 3. Like and Unlike Terms

### Like Terms

Terms having the same variables with the same powers.

```text
3x, 5x, -7x
```

They can be combined:

```text
3x + 5x - 7x = x
```

### Unlike Terms

```text
3x and 3x²
```

These cannot be directly combined.

```text
3x + 3x²
```

---

# 4. Simplifying Expressions

Combine like terms.

Example:

```text
3x + 5x - 2 + 7
```

```text
= 8x + 5
```

Another example:

```text
4a + 3b - 2a + 5b
```

```text
= 2a + 8b
```

---

# 5. Removing Brackets

Use the distributive property:

```text
a(b+c) = ab+ac
```

Example:

```text
3(x+5)
```

```text
= 3x + 15
```

For subtraction:

```text
-2(x-4)
```

```text
= -2x + 8
```

---

# 6. Linear Equation

A linear equation generally has the variable with power `1`.

Example:

```text
3x + 5 = 20
```

Subtract `5`:

```text
3x = 15
```

Divide by `3`:

```text
x = 5
```

---

# 7. Equation with Variables on Both Sides

Example:

```text
5x + 3 = 2x + 18
```

Move variable terms to one side:

```text
5x - 2x = 18 - 3
```

```text
3x = 15
```

```text
x = 5
```

### Rule

You can move a term across `=` by changing its sign.

---

# 8. Equations with Fractions

Example:

```text
x/3 + 5 = 9
```

Subtract `5`:

```text
x/3 = 4
```

Multiply by `3`:

```text
x = 12
```

### Shortcut

If an equation contains several fractions, multiply the entire equation by the **LCM of denominators**.

---

# 9. Equation with Decimals

Example:

```text
0.5x = 10
```

Therefore:

```text
x = 20
```

You can also multiply the equation by `10`, `100`, etc. to remove decimals.

---

# 10. Linear Equations with Brackets

Example:

```text
3(x+2) = 18
```

Expand:

```text
3x + 6 = 18
```

```text
3x = 12
```

```text
x = 4
```

# 11. Algebraic Identities

These identities are extremely important for aptitude.

### Identity 1

```text
(a+b)² = a² + 2ab + b²
```

### Identity 2

```text
(a-b)² = a² - 2ab + b²
```

### Identity 3

```text
(a+b)(a-b) = a²-b²
```

---

# 12. Cube Identities

### Sum of Cubes

```text
a³+b³ = (a+b)(a²-ab+b²)
```

### Difference of Cubes

```text
a³-b³ = (a-b)(a²+ab+b²)
```

---

# 13. Important Identity

```text
(a+b+c)²
= a²+b²+c²+2ab+2bc+2ca
```

This is useful when three variables are involved.

---

# 14. Identity-Based Questions

Suppose:

```text
a+b = 10
ab = 21
```

Find:

```text
a²+b²
```

Use:

```text
(a+b)² = a²+b²+2ab
```

Therefore:

```text
100 = a²+b²+42
```

```text
a²+b² = 58
```

---

# 15. Finding Product from Sum and Difference

If:

```text
a+b = S
a-b = D
```

Then:

```text
a = (S+D)/2
```

```text
b = (S-D)/2
```

### Example

```text
a+b = 18
a-b = 6
```

Therefore:

```text
a = (18+6)/2
  = 12
```

```text
b = (18-6)/2
  = 6
```

---

# 16. Difference of Squares

```text
a²-b² = (a-b)(a+b)
```

### Example

```text
99² - 1²
```

Instead of calculating both squares:

```text
= (99-1)(99+1)
= 98×100
= 9800
```

This is useful for fast aptitude calculations.

---

# 17. Factorisation

Factorisation means writing an expression as a product of simpler expressions.

Example:

```text
x²+5x+6
```

Find two numbers whose:

* product = `6`
* sum = `5`

They are `2` and `3`.

Therefore:

```text
x²+5x+6
= (x+2)(x+3)
```

---

# 18. Quadratic Equation

A quadratic equation has the form:

```text
ax²+bx+c = 0
```

where:

```text
a ≠ 0
```

Example:

```text
x²-5x+6 = 0
```

Factorise:

```text
(x-2)(x-3) = 0
```

Therefore:

```text
x = 2 or x = 3
```

---

# 19. Quadratic Formula

For:

```text
ax²+bx+c = 0
```

the roots are:

```text
x = [-b ± √(b²-4ac)]/(2a)
```

The expression:

```text
b²-4ac
```

is called the **discriminant**.

---

# 20. Discriminant

For:

```text
D = b²-4ac
```

### If `D > 0`

Two distinct real roots.

### If `D = 0`

Two equal real roots.

### If `D < 0`

No real roots.

For aptitude, most questions use factorisation or direct root properties rather than lengthy calculations.

---

# 21. Sum and Product of Roots

For:

```text
ax²+bx+c = 0
```

If roots are `α` and `β`:

```text
α+β = -b/a
```

```text
αβ = c/a
```

### Example

For:

```text
2x²-7x+3 = 0
```

```text
α+β = 7/2
```

```text
αβ = 3/2
```

---

# 22. Finding New Expressions from Roots

If:

```text
α+β = S
αβ = P
```

Then:

```text
α²+β² = (α+β)²-2αβ
```

Therefore:

```text
α²+β² = S²-2P
```

Also:

```text
(α-β)² = (α+β)²-4αβ
```

---

# 23. Reciprocal Roots

If roots are `α` and `β`:

```text
1/α + 1/β
= (α+β)/αβ
```

Therefore:

```text
1/α + 1/β = S/P
```

And:

```text
1/(αβ) = 1/P
```

---

# 24. Ratio-Based Algebra

Suppose:

```text
x:y = 3:5
```

Represent them as:

```text
x = 3k
y = 5k
```

This is one of the most useful algebra techniques in aptitude.

If:

```text
x+y = 32
```

then:

```text
3k+5k = 32
```

```text
8k = 32
```

```text
k = 4
```

Therefore:

```text
x = 12
y = 20
```

---

# 26. Consecutive Numbers

For consecutive integers:

```text
x, x+1, x+2, x+3
```

For consecutive even numbers:

```text
x, x+2, x+4, x+6
```

For consecutive odd numbers:

```text
x, x+2, x+4, x+6
```

The difference is always `2` for consecutive numbers of the same parity.

---

# 27. Three Consecutive Integers

Suppose their sum is `72`.

Represent them as:

```text
x, x+1, x+2
```

Then:

```text
x+(x+1)+(x+2)=72
```

```text
3x+3=72
```

```text
x=23
```

Numbers:

```text
23, 24, 25
```

# 28. Age Problems

Represent present age using a variable.

Example:

A father is 3 times as old as his son.

If son's age is `x`:

```text
Father = 3x
```

If their total age is `48`:

```text
x+3x = 48
```

```text
4x = 48
```

```text
x = 12
```

Therefore:

```text
Son = 12
Father = 36
```

---

# 29. Percentage in Algebra

If a number is increased by `20%`:

```text
New Value = 120x/100
```

```text
= 1.2x
```

If decreased by `20%`:

```text
New Value = 80x/100
```

```text
= 0.8x
```

This is useful when percentage and algebra are combined.

# 31. Inequalities

Inequalities use:

```text
>
<
≥
≤
```

Example:

```text
2x+3 > 9
```

```text
2x > 6
```

```text
x > 3
```

### Important Rule

When multiplying or dividing an inequality by a **negative number**, reverse the inequality sign.

Example:

```text
-2x > 6
```

Divide by `-2`:

```text
x < -3
```



# 35. Simplification Trick

If:

```text
x + 1/x = 5
```

find:

```text
x² + 1/x²
```

Square both sides:

```text
(x+1/x)² = 25
```

```text
x² + 2 + 1/x² = 25
```

Therefore:

```text
x² + 1/x² = 23
```

# 37. Common Traps

### Trap 1

```text
(a+b)² ≠ a²+b²
```

Correct:

```text
(a+b)² = a²+2ab+b²
```

### Trap 2

```text
(a-b)² ≠ a²-b²
```

Correct:

```text
(a-b)² = a²-2ab+b²
```

### Trap 3

When dividing an inequality by a negative number, reverse the sign.

### Trap 4

Do not cancel terms across addition.

Incorrect:

```text
(x+5)/x = 5
```

You cannot cancel `x` from only one term.

### Trap 5

For ratio:

```text
x:y = 3:5
```

use:

```text
x=3k, y=5k
```

not `x=3` and `y=5` unless the actual values are given.

# 38. Exam Strategy

For algebra questions:

1. Define the unknown using `x`.
2. Translate the statement into an equation.
3. Simplify brackets.
4. Collect like terms.
5. Factorise whenever possible.
6. Use identities for speed.
7. Check the final answer in the original equation.

### Fast Memory Sheet

```text
Linear:
ax+b=0

Quadratic:
ax²+bx+c=0

Roots:
α+β=-b/a
αβ=c/a

Identities:

(a-b)²=a²-2ab+b²
(a+b)(a-b)=a²-b²

Ratio:
x:y=m:n → x=mk, y=nk

Consecutive:

Even/Odd consecutive:

```
