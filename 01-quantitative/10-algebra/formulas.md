# Algebra — Formulas

## 1. Basic Algebra

```text
a(b+c) = ab+ac
```

```text
a(b-c) = ab-ac
```

---

## 2. Important Identities

```text
(a+b)² = a²+2ab+b²
```

```text
(a-b)² = a²-2ab+b²
```

```text
(a+b)(a-b) = a²-b²
```

```text
(a+b+c)²
= a²+b²+c²+2ab+2bc+2ca
```

---

## 3. Cube Identities

```text
a³+b³ = (a+b)(a²-ab+b²)
```

```text
a³-b³ = (a-b)(a²+ab+b²)
```

---

## 4. Factorisation

```text
x²+(a+b)x+ab
= (x+a)(x+b)
```

```text
x²-a² = (x-a)(x+a)
```

---

## 5. Quadratic Equation

```text
ax²+bx+c=0
```

### Quadratic Formula

```text
x = [-b ± √(b²-4ac)]/(2a)
```

---

## 6. Discriminant

```text
D = b²-4ac
```

| Discriminant | Roots                   |
| ------------ | ----------------------- |
| `D > 0`      | Two distinct real roots |
| `D = 0`      | Equal real roots        |
| `D < 0`      | No real roots           |

---

## 7. Roots of Quadratic

For roots `α, β`:

```text
α+β = -b/a
```

```text
αβ = c/a
```

---

## 8. Useful Root Expressions

```text
α²+β² = (α+β)²-2αβ
```

```text
(α-β)² = (α+β)²-4αβ
```

```text
1/α + 1/β = (α+β)/(αβ)
```

```text
1/(αβ) = 1/(αβ)
```

---

## 9. Sum and Difference

If:

```text
a+b=S
a-b=D
```

Then:

```text
a=(S+D)/2
```

```text
b=(S-D)/2
```

---

## 10. Difference of Squares

```text
a²-b²=(a-b)(a+b)
```

---

## 11. Ratio Representation

If:

```text
x:y=m:n
```

then:

```text
x=mk
y=nk
```

---

### Consecutive Integers

```text
x, x+1, x+2, ...
```

### Consecutive Even/Odd Numbers

```text
x, x+2, x+4, ...
```


```text

```


## 14. Surds

```text
√a×√b=√ab
```

```text
√a/√b=√(a/b)
```

```text
(√a+√b)(√a-√b)=a-b
```

---

## 15. Absolute Value

```text
|x|=a
```

For `a ≥ 0`:

```text
x=±a
```

---

## 16. Inequality Rule

If multiplying or dividing an inequality by a negative number:

```text
Sign must be reversed.
```

Example:

```text
-2x > 6
```

```text
x < -3
```

---

## 17. Percentage Algebra

Increase by `R%`:

```text
New Value = Old Value × (100+R)/100
```

Decrease by `R%`:

```text
New Value = Old Value × (100-R)/100
```

## 18. Quick Identity Table

| Identity                | Formula                 |
| ----------------------- | ----------------------- |
| Square of sum           | `(a+b)²=a²+2ab+b²`      |
| Square of difference    | `(a-b)²=a²-2ab+b²`      |
| Difference of squares   | `a²-b²=(a-b)(a+b)`      |
| Sum of cubes            | `a³+b³=(a+b)(a²-ab+b²)` |
| Difference of cubes     | `a³-b³=(a-b)(a²+ab+b²)` |
| Quadratic roots sum     | `-b/a`                  |
| Quadratic roots product | `c/a`                   |

---

## 19. Fast Algebra Rules

```text
Like terms → Add/Subtract coefficients

Ratio m:n → mk:nk

Linear equation → Collect x terms

Quadratic → Factorise or use formula

Same distance percentage → Use inverse relationship

Negative inequality division → Reverse sign
```
