# 1. RC Master Formula

```text
QUESTION SCAN
     ↓
PASSAGE
     ↓
TOPIC
     ↓
STRUCTURE
     ↓
EVIDENCE
     ↓
ELIMINATION
     ↓
ANSWER
```

---

# 2. Main Idea Formula

```text
MAIN IDEA
=
TOPIC
+
AUTHOR'S CENTRAL MESSAGE
```

### Test

Ask:

> Does this option explain most/all of the passage?

If yes → strong candidate.

If it describes only one paragraph → probably a detail.

---

# 3. Detail Formula

```text
QUESTION
 ↓
KEYWORD
 ↓
LOCATE
 ↓
READ SURROUNDING LINES
 ↓
ANSWER
```

### Rule

Don't rely on memory when you can verify the line.

---

# 4. Inference Formula

```text
PASSAGE FACTS
+
LOGICAL CONNECTION
=
INFERENCE
```

### NOT:

```text
PASSAGE
+
PERSONAL OPINION
=
❌
```

### Golden Rule

> **Inference = must be supported, not merely possible.**

---

# 5. Vocabulary Formula

```text
TARGET WORD
 ↓
READ SENTENCE
 ↓
READ SURROUNDING CONTEXT
 ↓
SUBSTITUTE OPTIONS
 ↓
CHECK MEANING
```

Don't automatically choose the most common dictionary meaning.

# 6. Tone Formula

```text
WORD CHOICE
+
AUTHOR'S ATTITUDE
+
OVERALL PASSAGE
=
TONE
```

### Positive Signals

```text
promising
beneficial
successful
effective
remarkable
```

Possible tone:

```text
optimistic
supportive
positive
```

### Negative Signals

```text
problem
danger
flawed
harmful
failure
```

Possible tone:

```text
critical
concerned
skeptical
```

### Neutral Signals

```text
data
research
analysis
study
according to
```

Possible tone:

```text
objective
analytical
informative
```

# 7. Purpose Formula

```text
WHY DID THE AUTHOR WRITE THIS?
```

Common answers:

```text
explain
inform
describe
compare
criticize
persuade
highlight
examine
discuss
```

---

# 8. Title Formula

```text
GOOD TITLE
=
CENTRAL IDEA
+
RIGHT SCOPE
```

Reject titles that are:

```text
too broad
too narrow
focused on one detail
unsupported
```

---

# 9. Elimination Formula

```text
OPTION
 ↓
Too broad? → ❌
Too narrow? → ❌
Contradicts passage? → ❌
Outside information? → ❌
Extreme? → ❌
Partially correct? → ❌
Supported by passage? → ✅
```


# 12. Final Cheat Sheet

| Question   | Ask Yourself                      |
| ---------- | --------------------------------- |
| Main Idea  | What is the whole passage saying? |
| Detail     | Where is this stated?             |
| Inference  | What logically follows?           |
| Vocabulary | What does this word mean here?    |
| Tone       | How does the author feel/write?   |
| Purpose    | Why was this written?             |
| Title      | What covers the entire passage?   |

### 🔥 One-Line Memory Trick

```text
MAIN → WHOLE
DETAIL → LINE
INFERENCE → LOGIC
VOCAB → CONTEXT
TONE → ATTITUDE
PURPOSE → WHY
TITLE → SUMMARY
```

### ⏱️ Time Rule

```text
Easy direct question → solve quickly
Inference → spend more time
Main idea → consider whole passage
Vocabulary → check context
```

> **Don't fight the passage. Find the evidence.**
