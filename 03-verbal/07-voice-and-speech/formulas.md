# 🧮 Voice and Speech — Formulas & Shortcuts

# 🟢 ACTIVE → PASSIVE

## Master Formula

```text
Active:
S + V + O

Passive:
O + Helping Verb + V3 + by + S
```

---

# ⏱️ Tense Formula Table

| Tense              | Active                    | Passive                    |
| ------------------ | ------------------------- | -------------------------- |
| Simple Present     | S + V1 + O                | O + am/is/are + V3         |
| Present Continuous | S + am/is/are + V-ing + O | O + am/is/are + being + V3 |
| Present Perfect    | S + has/have + V3 + O     | O + has/have + been + V3   |
| Simple Past        | S + V2 + O                | O + was/were + V3          |
| Past Continuous    | S + was/were + V-ing + O  | O + was/were + being + V3  |
| Past Perfect       | S + had + V3 + O          | O + had + been + V3        |
| Simple Future      | S + will + V1 + O         | O + will + be + V3         |
| Future Perfect     | S + will have + V3 + O    | O + will have been + V3    |

---

# 🧠 Helping Verb Shortcut

```text
Present:
am / is / are

Past:
was / were

Perfect:
been

Continuous:
being

Future:
be
```

---

# 🔥 Easy Memory Trick

```text
CONTINUOUS → BEING
PERFECT    → BEEN
FUTURE     → BE
```

Examples:

```text
is writing
↓
is being written


has written
↓
has been written


will write
↓
will be written
```

```text
Modal + V1
      ↓

```

Example:

```text
can solve
↓
can be solved

should complete
↓
should be completed

must follow
↓
must be followed
```

# ❓ Question Formula

## Yes/No

```text
Active:
Did + S + V1 + O?

Passive:
Was/Were + O + V3 + by + S?
```

Example:

```text
Did Ravi complete the work?

Was the work completed by Ravi?
```

---

# WH Question Formula

```text
Active:
WH + auxiliary + S + V + O?

Passive:
WH/by whom + auxiliary + O + V3?
```

Example:

```text
Who wrote the letter?

By whom was the letter written?
```

---

# 🚪 Imperative Formula

```text
V1 + O
↓
Let + O + be + V3
```

Example:

```text
Open the door.
↓
Let the door be opened.
```

# 🗣️ Statement Formula

```text
said + "statement"
        ↓
said + that + statement
```

Example:

```text
He said, "I am tired."
↓
He said that he was tired.
```

---

# 🟢 SAID vs TOLD

```text
said + statement

told + person + statement
```

Correct:

```text
He said that he was busy.

He told me that he was busy.
```

Incorrect:

```text
He told that he was busy.
```

# ❓ Yes/No Question

```text
said/asked:
"Are you ready?"

        ↓

asked + object + if/whether + statement order
```

Example:

```text
He said to me, "Are you ready?"

He asked me if I was ready.
```

---

# ❓ WH Question

```text
WH word remains
+
statement word order
```

Example:

```text
She said, "Where do you live?"

She asked me where I lived.
```

---

# 🛠️ Command

```text
said to
 ↓
told

V1
 ↓
to + V1
```

Example:

```text
He said to me, "Work hard."

He told me to work hard.
```

---

# 🚫 Negative Command

```text
Do not + V1
       ↓
not to + V1
```

Example:

```text
He said, "Do not run."

He told me not to run.
```
