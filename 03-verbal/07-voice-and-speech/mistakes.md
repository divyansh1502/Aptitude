# 🔴 Common Voice Mistakes

## 1. Forgetting V3 — `C`

Wrong:

```text
The work was complete by him.
```

Correct:

```text
The work was completed by him.
```

### Rule

```text
Passive → V3
```

---

# 2. Wrong Helping Verb — `G`

Example:

```text
The letters was written...
```

Wrong.

```text
The letters were written...
```

Correct.

### Rule

```text
Singular → was
Plural → were
```

---

# 3. Forgetting "being" — `C`

Active:

```text
The team is developing the application.
```

Passive:

```text
The application is being developed.
```

Not:

```text
The application is developed.
```

---

# 4. Forgetting "been" — `C`

Active:

```text
They have completed the work.
```

Passive:

```text
The work has been completed.
```

---

# 5. Wrong Future Passive — `G`

Wrong:

```text
The results will announced.
```

Correct:

```text
The results will be announced.
```

### Rule

```text
will + be + V3
```

---

# 6. Adding "by" unnecessarily — `S`

Sometimes the agent is unknown or irrelevant.

```text
My phone was stolen.
```

is perfectly correct.

You do not always need:

```text
by someone
```

# 🔵 Common Speech Mistakes

## 7. Wrong Backshift — `C`

Direct:

```text
He said, "I am tired."
```

Correct:

```text
He said that he was tired.
```

---

# 8. Wrong Pronoun — `G`

Direct:

```text
Rahul said, "I am ready."
```

Wrong:

```text
Rahul said that I was ready.
```

Correct:

```text
Rahul said that he was ready.
```

---

# 9. Wrong Time Expression — `G`

Remember:

```text
today → that day
tomorrow → next day
yesterday → previous day
now → then
here → there
```

---

# 10. Using "Told" Without Object — `G`

Wrong:

```text
He told that he was tired.
```

Correct:

```text
He said that he was tired.
```

OR:

```text
He told me that he was tired.
```

---

# 11. Wrong Indirect Question Order — `C`

Wrong:

```text
She asked where was I going.
```

Correct:

```text
She asked where I was going.
```

### Rule

```text
Indirect question → statement word order
```

---

# 12. Forgetting IF/WHETHER — `C`

Direct:

```text
He asked, "Are you ready?"
```

Correct:

```text
He asked if I was ready.
```

---

# 13. Treating WH Questions Like Yes/No Questions — `G`

Direct:

```text
She asked, "Where do you live?"
```

Correct:

```text
She asked where I lived.
```

Do not add:

```text
if
```

---

# 14. Command Conversion Error — `C`

Direct:

```text
He said to me, "Work hard."
```

Correct:

```text
He told me to work hard.
```

Pattern:

```text
told + object + to + V1
```

---

# 15. Negative Command Error — `G`

Direct:

```text
He said, "Do not run."
```

Correct:

```text
He told me not to run.
```

Pattern:

```text
not to + V1
```

# 🏆 Final Memory Rules

```text
VOICE
→ Object + Helping Verb + V3

CONTINUOUS
→ being

PERFECT
→ been

FUTURE
→ be


SPEECH
→ Tense + Pronoun + Time/Place

YES/NO
→ if/whether

WH
→ WH + statement order

COMMAND
→ told + object + to

NEGATIVE COMMAND
→ told + object + not to
```

> **If you can identify the structure, most Voice & Speech questions become mechanical rather than guesswork.**
