# 1. Vocabulary Formula

```text
WORD
 ↓
PART OF SPEECH
 ↓
CORE MEANING
 ↓
CONTEXT
 ↓
SYNONYM / ANTONYM
 ↓
USAGE
```

---

# 2. Synonym Shortcut

When asked for a synonym:

```text
Given word
    ↓
Say meaning in simple English
    ↓
Match same meaning
    ↓
Check part of speech
    ↓
Select
```

### Example

```text
Rapid
↓
very fast
↓
quick
```

---

# 3. Antonym Shortcut

```text
Given word
    ↓
Find exact meaning
    ↓
Find opposite concept
    ↓
Check options
```

### Example

```text
Expand
↓
become larger
↓
contract
```

---

# 4. Context Shortcut

If a word has multiple meanings:

```text
WORD
 ↓
READ COMPLETE SENTENCE
 ↓
IDENTIFY INTENDED MEANING
 ↓
SUBSTITUTE OPTION
```

### Example

```text
address a problem
→ deal with a problem

address = location
→ address of the office
```

# 7. Part-of-Speech Shortcut

### Noun

Often:

```text
-tion
-ment
-ness
-ity
```

Examples:

```text
education
development
kindness
ability
```

### Adjective

Often:

```text
-ful
-less
-able
-ous
-ive
```

Examples:

```text
useful
careless
readable
dangerous
creative
```

### Adverb

Often:

```text
-ly
```

Examples:

```text
quickly
carefully
successfully
```

⚠️ Not every `-ly` word is an adverb.

# 8. Idiom Shortcut

Never translate idioms word-by-word.

```text
Idiom
 ↓
Known figurative meaning
 ↓
Sentence context
```

### Quick List

```text
piece of cake → very easy
break the ice → start interaction
spill the beans → reveal a secret
once in a blue moon → rarely
call it a day → stop working
burn the midnight oil → work late
under the weather → feel unwell
in hot water → in trouble
hit the nail on the head → exactly right
beat around the bush → avoid the main point
```

# 9. Phrasal Verb Shortcut

Learn:

```text
Phrasal verb → meaning → example
```

```text
look into → investigate
look after → take care of
give up → quit
put off → postpone
call off → cancel
carry out → perform
set up → establish
take over → assume control
find out → discover
figure out → understand/solve
```

# 10. Confusing Words

```text
affect → usually verb
effect → usually noun

advice → noun
advise → verb

accept → receive/agrees
except → excluding

principal → main/head
principle → rule

compliment → praise
complement → complete/improve

its → possession
it's → it is

your → possession
you're → you are

their → possession
there → place
they're → they are

then → time
than → comparison
```

# 12. Final Cheat Sheet

### 🔥 If you know the word

```text
Meaning → match option
```

### 🔥 If you partially know the word

```text
Root/prefix → infer meaning → eliminate
```

### 🔥 If you don't know the word

```text
Context → part of speech → tone → elimination
```

### 🔥 If it is an idiom

```text
Don't translate literally.
```

### 🔥 If it is a synonym/antonym

```text
Match the exact sense, not just a related word.
```

### 🔥 If two options look similar

```text
Put both into the original sentence.
```

> **Context + usage beats memorization alone.**
