## 1. Tense Structures

| Tense | Simple | Continuous | Perfect | Perfect Continuous |
|---|---|---|---|---|
| **Present** | V1 / V1+s | is/am/are + V-ing | has/have + V3 | has/have been + V-ing |
| **Past** | V2 | was/were + V-ing | had + V3 | had been + V-ing |
| **Future** | will + V1 | will be + V-ing | will have + V3 | will have been + V-ing |

### Tense signals

| Clue word | Tense |
|---|---|
| since, for, already, yet, just, ever, never, so far | Present perfect |
| yesterday, ago, last (week/year), in 2019 | Simple past |
| now, at present, currently, at the moment | Present continuous |
| by the time, before (two past events) | Earlier event → past perfect |
| by next week / by 2030 | Future perfect |
| if / when / before / after / as soon as (future meaning) | Present tense in the clause, **no "will"** |

## 2. Subject-Verb Agreement Cheat Sheet

| Situation | Rule | Example |
|---|---|---|
| each, every, either, neither, one of, everyone, somebody | Singular | Each of the boys **is** present. |
| Either…or / Neither…nor / Not only…but also | Agrees with **nearer** subject | Neither he nor his friends **were** there. |
| with, along with, as well as, together with, in addition to | Agrees with **first** subject | The CEO, along with his team, **is** here. |
| A number of | Plural | A number of students **are** absent. |
| The number of | Singular | The number of students **is** rising. |
| Many a + singular noun | Singular | Many a man **has** tried. |
| Uncountable nouns | Singular | The information **is** useful. |
| Plural-only nouns | Plural | The scissors **are** sharp. |
| Subjects joined by "and" | Plural | Ram and Shyam **are** friends. |
| Subjects joined by "and" forming one idea | Singular | Rice and curry **is** my favourite. |
| Distance / money / time as a single unit | Singular | Ten kilometres **is** far. |
| Collective noun acting as one unit | Singular | The team **has** won. |
| Collective noun, members acting separately | Plural | The team **are** arguing among themselves. |
| Title of a book or film | Singular | *Gulliver's Travels* **is** interesting. |

**Always-singular words:** furniture, information, advice, news, luggage, equipment, knowledge, scenery, mathematics, physics, economics.

**Always-plural words:** people, police, cattle, scissors, trousers, jeans, spectacles.

## 3. Articles

| Condition | Article |
|---|---|
| Consonant **sound** | a (*a university, a one-rupee coin, a European*) |
| Vowel **sound** | an (*an hour, an honest man, an MBA*) |
| Specific, unique or already mentioned | the (*the sun, the book I bought*) |
| Superlative or ordinal | the (*the best, the first*) |
| Rivers, oceans, seas, mountain ranges | the (*the Ganga, the Himalayas*) |
| Languages, meals, most sports | no article |
| General plural or abstract noun | no article |

## 4. Prepositions

### Time

| Preposition | Use | Example |
|---|---|---|
| **at** | Exact time | at 5 PM, at noon, at night |
| **on** | Days, dates | on Monday, on 5 May |
| **in** | Months, years, seasons, parts of day | in May, in 2024, in the morning |
| **since** | Starting point | since 2019 |
| **for** | Duration | for 3 hours |
| **by** | Deadline (not later than) | by Friday |
| **until / till** | Up to a time | until 6 PM |

### Place

| Preposition | Use |
|---|---|
| **at** | Specific point (at the gate) |
| **on** | Surface (on the table) |
| **in** | Inside an area (in the room, in Pune) |

### Must-know fixed pairs

| Preposition | Words |
|---|---|
| **at** | good at, bad at, weak at, surprised at |
| **in** | interested in, involved in, believe in |
| **of** | afraid of, fond of, proud of, capable of, aware of, jealous of, ashamed of |
| **to** | married to, similar to, superior to, inferior to, addicted to, accustomed to, prefer … to |
| **from** | different from, differ from, protect from |
| **on** | depend on, insist on, rely on, congratulate on |
| **for** | responsible for, famous for, ask for, wait for |
| **with** | angry with (person), agree with (person), comply with |
| **into** | divided into, turn into |

### No preposition after these verbs

discuss · enter · reach · marry · resemble · attend · approach · return (not "return back")

## 5. Pronouns

| Case | Words |
|---|---|
| **Subject** | I, we, you, he, she, it, they, who |
| **Object** | me, us, you, him, her, it, them, whom |
| **Possessive** | my/mine, our/ours, your/yours, his, her/hers, its, their/theirs |
| **Reflexive** | myself, ourselves, yourself, himself, herself, itself, themselves |

### Quick rules

- After a **preposition** → object case. *Between you and **me**.*
- Each, every, everyone, anyone, nobody → **singular** pronoun.
- **Who** = does the action. **Whom** = receives the action.
- Reflexive only when subject and object are the same person.
- **Its** = belonging to it. **It's** = it is / it has.
- Make sure every pronoun has a **clear** noun it refers to.

## 6. Modifiers

| Problem | Fix |
|---|---|
| Modifier is far from the word it describes | Move it next to that word |
| Opening phrase doesn't match the subject after the comma | Make the subject the doer of the opening action |
| "Only" in the wrong place | Place it right before the word it limits |

## 7. Commonly Confused Words

| Pair | Difference |
|---|---|
| **affect / effect** | affect = verb (to influence); effect = noun (result) |
| **fewer / less** | fewer = countable; less = uncountable |
| **much / many** | much = uncountable; many = countable |
| **lose / loose** | lose = misplace/fail; loose = not tight |
| **than / then** | than = comparison; then = time or sequence |
| **their / there / they're** | their = belonging to them; there = place; they're = they are |
| **its / it's** | its = possessive; it's = it is |
| **who / whom** | who = subject; whom = object |

## 8. 10-Second Error-Spotting Checklist

1. Find the real **subject**, then check the **verb**.
2. Check **tense** vs signal words.
3. Check **pronoun** number and case.
4. Check **article** (sound, not spelling).
5. Check **preposition** (fixed pair?).
6. Check **modifier** placement.
7. If nothing is wrong, the answer is "No error".
