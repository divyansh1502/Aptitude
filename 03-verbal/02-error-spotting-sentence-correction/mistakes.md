# 🎯 How to Use

Don't copy every wrong question here.

Add a mistake when:

* you didn't know the rule,
* you repeatedly make the same error,
* you knew the rule but still applied it incorrectly,
* you keep confusing two similar structures.

The goal is to build your **personal grammar trap sheet**.

# ⚠️ Common Traps

## 1. Subject–Verb Agreement

```text
Each student has...
Every student is...
A number of students are...
The number of students is...
```

---

## 2. Prepositions

```text
good at
interested in
capable of
responsible for
depend on
different from
similar to
senior to
```

---

## 3. Articles

```text
a university
a European
an honest man
an hour
an MBA
```

---

## 4. Comparison

```text
better than
more useful than
the best
one of the best students
```

Avoid:

```text
more better ❌
most fastest ❌
one of the best student ❌
```

---

## 5. Redundancy

```text
discuss about ❌
return back ❌
repeat again ❌
past history ❌
```

---

## 6. Parallelism

```text
reading + writing + travelling
```

Not:

```text
reading + writing + to travel ❌
```

---

## 7. Conditionals

```text
If I study, I will pass.

If I studied, I would pass.

If I had studied, I would have passed.
```

# 🔁 Revision Cycle

If the same mistake appears **3 times**:

```text
Third mistake
     ↓
Read the rule
     ↓
Explain it in your own words
     ↓
Write 2 correct examples
     ↓
Write 1 trap example
     ↓
Solve 5 similar questions
     ↓
Re-test after 2–3 days
```

# 🧠 Example

### Mistake

> The number of students **have** increased.

### Why I got it wrong

I matched the verb with **students** instead of **number**.

### Correct

> The number of students **has** increased.

### Rule

> The number of + plural noun → singular verb.

### Memory Trick

```text
THE number → one total → singular

A number → several → plural
```

# ✅ Quick Checklist

Before submitting:

* [ ] Did I identify the real subject?
* [ ] Does the verb agree with it?
* [ ] Is the tense correct?
* [ ] Is the article correct?
* [ ] Is the preposition correct?
* [ ] Is the pronoun correct?
* [ ] Is the modifier placed correctly?
* [ ] Is the sentence parallel?
* [ ] Is the comparison correct?
* [ ] Is there unnecessary repetition?
* [ ] Is the word used correctly?
* [ ] Did I read the entire sentence?
