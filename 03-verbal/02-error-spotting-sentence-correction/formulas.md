# Subject–Verb Agreement

```text
Each / Every / Everyone → singular
A number of → plural
The number of → singular
One of the + plural noun → singular verb
Either A or B → verb follows B
Neither A nor B → verb follows B
Along with / As well as → main subject decides
```

Examples:

```text
Each student has...
A number of students are...
The number of students is...
The manager, along with his team, is...
```

# Tenses

### Past Sequence

```text
Earlier past action → had + V3
Later past action   → V2
```

### Present Perfect

```text
has/have + V3
```

### Past Perfect

```text
had + V3
```

### Since / For

```text
since → point
for → duration
```

### Finished Past Time

```text
yesterday
last week
last year
two days ago
```

→ normally use **simple past**, not present perfect.

# Articles

```text
a  → consonant sound
an → vowel sound
the → specific/unique reference
```

Examples:

```text
a university
a European
an hour
an honest man
an MBA
```

# Prepositions

### Time

```text
at → exact time
on → day/date
in → month/year/period
```

### Common Combinations

```text
good at
interested in
capable of
responsible for
depend on
belong to
consist of
similar to
different from
superior to
senior to
```

### Common Corrections

```text
discuss the issue       ❌ discuss about
enter the room          ❌ enter into
explain it to me        ❌ explain me
```

# Pronouns

```text
Subject → I, we, he, she, they
Object  → me, us, him, her, them
```

Examples:

```text
Rahul and I went.
The teacher called Rahul and me.
```

### Who / Whom

```text
who  → subject
whom → object
```

# Comparison

### Comparative

```text
adjective + er + than
more + adjective + than
```

### Superlative

```text
the + adjective + est
the most + adjective
```

### Avoid

```text
more better ❌
more easier ❌
most fastest ❌
```

### One of

```text
one of the + superlative + plural noun
```

---

# Parallelism

```text
A + B + C
```

should use the same grammatical form.

Example:

```text
reading
writing
travelling
```

### Correlative Pairs

```text
both...and
either...or
neither...nor
not only...but also
```

---

# Modifiers

```text
Modifier → place near the word it describes
```

Ask:

> Who is performing the action?

Avoid:

> Walking to college, the rain started. ❌

---

# Conjunctions

### Although

```text
Although + clause, clause
```

Avoid:

```text
Although...but ❌
```

### Unless

```text
unless = if not
```

---

# Redundancy

```text
return back → return
repeat again → repeat
discuss about → discuss
past history → history
free gift → gift
revert back → revert
```

---

# Conditionals

### Type 1

```text
If + present → will + V1
```

### Type 2

```text
If + past → would + V1
```

### Type 3

```text
If + had + V3 → would have + V3
```

# Word Usage

```text
affect → usually verb
effect → usually noun

its → possession
it's → it is / it has

your → possession
you're → you are

their → possession
there → place/existence
they're → they are

then → time/order
than → comparison

advice → noun
advise → verb
```

# Error Spotting Order

Remember:

```text
S → V → T → A → P → P → M → C → W
```

```text
S = Subject
V = Verb
T = Tense
A = Article
P = Preposition
P = Pronoun
M = Modifier
C = Comparison/Conjunction
W = Word Usage
```
