## Q1. HCF / LCM

**Type:** PATTERN

Find the LCM of:

```text id="v0oq8m"
12, 18, 30
```

Solution:

```text id="4p9e3s"
12 = 2² × 3
18 = 2 × 3²
30 = 2 × 3 × 5
```

Therefore:

```text id="6ck1o8"
LCM = 2² × 3² × 5
    = 180
```

**Answer:** 180

## Q5. Average

**Type:** PATTERN

New Average = 208 / 8
            = 26

## Q12. Mixture

**Type:** PATTERN

Two liquids are mixed in a specified ratio. Find the quantity of each liquid for a given total volume.

### Core technique

```text id="4m4qgx"
Ratio = a:b

Total parts = a+b

First quantity
= Total × a/(a+b)

Second quantity
= Total × b/(a+b)
```

## Q19. Coding-Decoding

**Type:** REPORTED

A public Wipro reasoning collection gives:

```text id="0tmyo9"
LUCKNOW → NWEMPQY
```

The rule is shifting each character by 2 positions:

```text id="a3d9w2"
L → N
U → W
C → E
K → M
N → P
O → Q
W → Y
```

Therefore:

```text id="h3u7i8"
SARK → UCTM
```

**Answer:** UCTM

This question appears in a Wipro NTH coding-decoding collection. ([prepinsta.com](https://prepinsta.com/wipro-nlth/placement-papers/logical-reasoning/coding-deductive-logic/quiz-1/?utm_source=chatgpt.com))

## Q20. Coding-Decoding

**Type:** REPORTED

A public Wipro collection gives:

```text id="f9d7n2"
MISTER → 131776218
```

The coding uses the complement of each letter's alphabet position with respect to 26:

```text id="0r8g4a"
M → 26 - 13 = 13
I → 26 - 9  = 17
S → 26 - 19 = 7
T → 26 - 20 = 6
E → 26 - 5  = 21
R → 26 - 18 = 8
```

For:

```text id="9q9z0j"
PAWAN
```

the reported result is:

```text id="v5c4nd"
102532512
```

([prepinsta.com](https://prepinsta.com/wipro-nlth/placement-papers/logical-reasoning/coding-deductive-logic/quiz-1/?utm_source=chatgpt.com))

# 11. Common Traps

## Quantitative

### Trap 1 — Successive Percentage

Never simply add percentage changes.

```text id="5q7m2x"
+20% then -10%

≠ +10%

= +8%
```

---

### Trap 2 — Time & Work

Never add completion times.

Wrong:

```text id="9k3v5p"
20 + 30
```

Correct:

```text id="2m8j6q"
1/20 + 1/30
```

---

### Trap 3 — Units

Always check:

```text id="4r7n1s"
km/h
m/s
hours
minutes
```

---

## Reasoning

### Trap 4 — Coding-Decoding

First identify the rule.

Do not assume every question uses:

```text id="7p4m2k"
+1
```

Possible rules include:

```text
+2
-1
reverse
alphabet complement
position-based arithmetic
```

---

### Trap 5 — Data Sufficiency

You are not necessarily required to find the answer.

You need to determine whether the information is sufficient.

---

## Verbal

### Trap 6 — Grammar by Sound

Check the actual grammar rule instead of choosing what sounds natural.

---

## Coding

### Trap 7 — Brute Force

Before nested loops, ask:

```text id="3m8q6v"
Can I sort?
Can I hash?
Can I use prefix sum?
Can I use two pointers?
Can I use sliding window?
```

---

### Trap 8 — Integer Overflow

Use `long` when calculations may exceed `int`.

---

### Trap 9 — Edge Cases

Always test:

```text id="7k2p5m"
Empty input
One element
Duplicates
Zero
Negative values
Already sorted
Very large values
```
