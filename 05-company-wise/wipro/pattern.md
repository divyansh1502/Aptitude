# 1. Overview

**Wipro Elite NTH (National Talent Hunt)** is a fresher hiring assessment used for engineering graduates.

The commonly reported recent structure contains:

```text id="8m2xkd"
                 WIPRO ELITE NTH
                       │
             ┌─────────┼─────────┐
             │         │         │
          APTITUDE   WRITING   CODING
             │
       ┌─────┼─────┐
       │     │     │
     Quant Logical Verbal
```

Recent placement sources report:

* Quantitative Ability
* Logical Reasoning
* Verbal English
* Written Communication
* Coding

The reported 2025 structure is:

| Section               | Questions |    Time |
| --------------------- | --------: | ------: |
| Quantitative Ability  |        16 | 16 min* |
| Logical Reasoning     |        14 | 14 min* |
| Verbal English        |        18 | 18 min* |
| Written Communication |         1 |  20 min |
| Coding                |         2 |  60 min |

*Some sources describe Quant + Logical + Verbal as a **combined 48-minute aptitude section**, rather than three separately timed sections. ([prepinsta.com](https://prepinsta.com/wipro-nlth/placement-papers/?utm_source=chatgpt.com))

Therefore, for preparation:

```text id="m7i4dy"
48 min
│
├── Quant
├── Logical
└── Verbal
```

rather than assuming that the three areas will always have independently enforced timers.

# 2. Important Pattern Note

Wipro has multiple fresher programs.

Do not combine these into one guaranteed exam:

```text id="mab3d7"
Wipro Elite NTH
Wipro Turbo
Wipro WILP
Other role-specific drives
```

The Elite and Turbo assessments reported for 2025 had very similar aptitude/writing/coding structures, but role-specific recruitment can differ. ([prepinsta.com](https://prepinsta.com/wipro-turbo/syllabus/?utm_source=chatgpt.com))

### Repository rule

```text
Current recruitment notification
          ↓
Specific Wipro drive
          ↓
Actual assessment pattern
          ↓
Preparation syllabus
```

The question counts below should therefore be treated as a **recent preparation baseline**, not a permanent Wipro specification.

# 5. Written Communication

Wipro's reported Elite assessment includes one written communication/essay question with approximately **20 minutes**. ([prepinsta.com](https://prepinsta.com/wipro-nlth/placement-papers/?utm_source=chatgpt.com))

A 2025 candidate experience also reported a 20-minute essay-writing round. ([geeksforgeeks.org](https://www.geeksforgeeks.org/interview-experiences/wipro-elite-interview-experience-on-campus/?utm_source=chatgpt.com))

## What is evaluated

```text id="f5b2d1"
Written Communication
│
├── Grammar
├── Spelling
├── Punctuation
├── Vocabulary
├── Sentence Structure
├── Organization
├── Relevance
└── Clarity
```

## Recommended structure

```text id="y3c1j4"
Introduction
     ↓
Main Argument
     ↓
Supporting Point 1
     ↓
Supporting Point 2
     ↓
Example
     ↓
Conclusion
```

### Target

Write approximately:

```text
100–400 words
```

when the particular test specifies that range. A recent candidate experience reported a 100–400-word essay in 20 minutes. ([geeksforgeeks.org](https://www.geeksforgeeks.org/interview-experiences/wipro-elite-interview-experience-on-campus/?utm_source=chatgpt.com))

# 10. Exam Strategy

## Aptitude

The biggest challenge is **speed**.

The reported 48-minute aptitude structure means you should practice:

```text id="6e4s1w"
Easy question
     ↓
Solve immediately

Medium question
     ↓
Try quickly

Time-consuming question
     ↓
Skip / return later
```

### Target

Do not spend several minutes on one quantitative question when the test is designed around rapid problem solving.

---

## Writing

Before writing:

```text id="1s8m0z"
1 minute → Think
2 minutes → Outline
14–15 minutes → Write
2–3 minutes → Proofread
```

---

## Coding

For each problem:

```text id="yk2u6f"
Understand
   ↓
Examples
   ↓
Brute-force idea
   ↓
Optimize
   ↓
Code
   ↓
Test edge cases
```
