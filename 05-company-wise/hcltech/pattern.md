# 3. Online Assessment

## Reported Formats

One 2025 HCLTech GET campus experience reported:

| Section                  | Reported Questions | Reported Time |
| ------------------------ | -----------------: | ------------: |
| Quantitative / Numerical |                 15 |        15 min |
| Logical Reasoning        |                 15 |        15 min |
| Verbal Ability           |                 15 |        15 min |
| Computer Fundamentals    |                 30 |        30 min |
| Coding                   |                  2 |        20 min |
| **Total**                |             **77** |   **100 min** |

This is one candidate's reported format, **not a universal HCLTech pattern**.

Another 2025 GET experience reported an online assessment containing **75 questions in 90 minutes**, covering coding-based exercises, technical MCQs, logical/verbal/quantitative reasoning and analytical/critical reasoning.

A 2025 off-campus report described a roughly **95-minute** assessment containing aptitude/verbal, two coding questions, one SQL query and technical MCQs.

### Therefore:

```text
Do NOT memorize:
"Exactly X questions in Y minutes"

Instead prepare for:
Aptitude
+
Reasoning
+
English
+
Technical fundamentals
+
Pseudocode
+
Coding
+
SQL
```

# 9. Communication / Group Discussion

Some HCLTech hiring drives include a communication or GD stage.

A 2025 GET experience reported a virtual GD where candidates had approximately two minutes to speak. Another reported a GD topic of:

> **"Pros and Cons of AI"**

These are candidate-reported examples, not guaranteed future topics.

## Prepare Topics

```text
Artificial Intelligence
Generative AI
Work From Home
Social Media
Technology in Education
Online Education
Cybersecurity
Climate Change
Digital India
Automation
Remote Work
AI and Jobs
```

## GD Strategy

```text
Listen
   ↓
Understand the topic
   ↓
Form one clear point
   ↓
Speak
   ↓
Support with an example
   ↓
Let others speak
   ↓
Add another point if useful
```

Avoid:

* Interrupting repeatedly
* Speaking continuously
* Going completely silent
* Personal attacks
* Unclear arguments

# 15. Important Pattern Warning

HCLTech is particularly important to treat as **drive-specific**.

Recent reports demonstrate this clearly:

### Report A — GET campus

```text
75 questions
90 minutes
Coding
Technical MCQs
Quant
Logical
Verbal
Analytical reasoning
```

### Report B — On-campus

```text
Quant
Logical
Verbal
Computer Fundamentals
2 Coding Questions
```

### Report C — Off-campus

```text
Aptitude
Verbal
2 Coding Questions
1 SQL Query
Technical MCQs
```

### Report D — 2026 GET discussion

A recent candidate discussion described:

```text
Aptitude + Coding
        ↓
Communication
        ↓
Technical Interview
        ↓
Role-based training/course
        ↓
Hackathon
        ↓
HR
```

This is candidate-reported and should **not** be treated as HCLTech's universal process.

### Bottom line

Prepare the **common core**, then follow the exact assessment invitation for your drive.

```text
COMMON CORE
     ↓
Aptitude
Reasoning
English
Technical MCQs
Coding
SQL
Communication
Interview
```

HCLTech itself currently lists college graduates as a dedicated career pathway and has active campus/fresher roles, reinforcing that the exact role and hiring program matter.
