# Capgemini Placement Pattern

> **Last researched:** October 2026
> **Target:** Capgemini India — Exceller / Fresher Hiring
> **Focus:** Analyst / Senior Analyst / Software Engineer tracks

---

# ⚠️ Important Pattern Note

Capgemini's fresher assessment pattern has changed significantly from the older aptitude-based format.

The **older pattern** commonly contained:

* Quantitative Aptitude
* Logical Reasoning
* Technical MCQs
* Essay / Written English

The **recent 2026 pattern** has shifted toward:

* Technical MCQs
* Pseudocode
* Written English / Communication
* Game-based Cognitive Assessment
* Coding
* Spoken English
* Technical + HR Interview

Capgemini's official India recruitment page confirms that assessments may include **technical and language assessments**, followed by technical and HR interviews depending on the position.

> **Golden rule:** Your Capgemini assessment invitation/college placement notification is the final authority because the exact process can vary by drive and role.

# ⏱️ Exam Strategy

## Pseudocode

Use:

```text
Read
 ↓
Trace variables
 ↓
Track loop
 ↓
Check condition
 ↓
Calculate output
```

Don't solve it mentally without writing the variable state when the code becomes complex.

---

## Coding

Use:

```text
Read problem
 ↓
Understand constraints
 ↓
Identify pattern
 ↓
Write approach
 ↓
Code
 ↓
Test edge cases
```

### First ask:

```text
Can HashMap help?
Can sorting help?
Can two pointers help?
Can sliding window help?
Can prefix sum help?
```

---

## Cognitive Games

The goal is:

```text
Accuracy > Random Speed
```

Learn the rules quickly and avoid careless mistakes.

# ⚠️ Common Mistakes

### ❌ Mistake 1

Preparing the old Capgemini Quant paper as your main preparation.

### ❌ Mistake 2

Ignoring pseudocode.

### ❌ Mistake 3

Practicing only difficult LeetCode problems.

### ❌ Mistake 4

Ignoring English communication.

### ❌ Mistake 5

Ignoring SQL and DBMS.

### ❌ Mistake 6

Assuming one 2025 pattern is guaranteed for a 2026/2027 drive.

Recent reports show that Capgemini has continued changing its process. A September 2026 candidate discussion, for example, describes a newer flow involving communication, problem solving, AI-assisted debugging/feature development, prompt engineering and cognitive assessment. Treat such reports as drive-specific until confirmed by the placement notification.
