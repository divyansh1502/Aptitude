# 1. Overview

Infosys conducts multiple fresher hiring and assessment programs rather than using one permanently fixed aptitude paper.

Commonly encountered tracks include:

* General fresher/System Engineer hiring
* Specialist Programmer / Digital Specialist Engineer hiring
* HackWithInfy
* InfyTQ

Infosys itself describes its campus hiring as involving structured assessments followed by interviews, while its current careers material also identifies multiple entry-level roles such as System Engineering Trainee, Digital Specialist Engineer and Specialist Programmer.

Therefore:

```text
                 INFOSYS
                    │
        ┌───────────┼────────────┐
        │           │            │
      General    HackWithInfy   InfyTQ
      Fresher        │            │
        │        Coding-heavy   Certification
        │                       + Advantage
        ▼
 Aptitude + Technical
 + Pseudocode + English
```

# 2. Important Pattern Note

There is **no single permanent Infosys aptitude pattern** that should be assumed for every hiring drive.

Recent candidate reports show different configurations.

For example, one 2025 System Engineer assessment reported:

* 7 sections
* 120 minutes
* Logical Ability
* Technical Ability
* Verbal
* Pseudocode
* Puzzle Solving
* English Grammar
* English Writing

Another 2025 assessment reported a 2-hour test with aptitude, logical reasoning, verbal ability, mental ability, programming, pseudocode and essay writing.

So this repository uses:

```text
OFFICIAL / CURRENT NOTIFICATION
              ↓
        PRIMARY SOURCE
              ↓
     DRIVE-SPECIFIC PATTERN
              ↓
      PREPARATION SYLLABUS
```

**Always check the specific Infosys/TPO hiring notification before the actual test.**

# 3. General Fresher Assessment

A frequently reported System Engineer-style assessment contains aptitude, reasoning, verbal and programming-logic components.

A 2025 candidate report described a **120-minute assessment with seven sections**.

### Reported 2025–26 configuration

| Section           | Questions |        Time |
| ----------------- | --------: | ----------: |
| Logical Reasoning |        15 |      25 min |
| Technical Ability |        10 |      35 min |
| Verbal Ability    |        20 |      20 min |
| Pseudocode        |         5 |      10 min |
| Puzzle Solving    |         4 |      10 min |
| English Grammar   |         5 |      10 min |
| English Writing   |         1 |      10 min |
| **Total**         |    **60** | **120 min** |

This configuration is **reported by placement-preparation sources/candidate experiences**, not a universal official Infosys specification.

### Historical comparison

Older System Engineer assessments have reported a shorter structure such as:

| Section               | Questions |   Time |
| --------------------- | --------: | -----: |
| Logical Reasoning     |        15 | 25 min |
| Quantitative Aptitude |        10 | 35 min |
| Verbal Ability        |        20 | 20 min |
| Pseudocode            |         5 | 10 min |
| Puzzle Solving        |         4 | 10 min |

Total: approximately 100 minutes.

### Repository rule

Do **not** memorize the question count.

Memorize the skill areas.

# 6. Specialized Infosys Tracks

## 6.1 HackWithInfy

HackWithInfy is a coding-focused Infosys program.

Infosys's preparatory guidance describes an online test with:

* 3 coding questions
* 3 hours
* Sectional cut-off
* Total cut-off

The questions are described at different difficulty levels:

```text
Easy   → Basic application of algorithms / DS
Medium → Usually Greedy
Hard   → Usually Dynamic Programming
```

Supported languages in the published guidance include C, C++, Java, Python and JavaScript.

```text
HackWithInfy
│
├── Easy
│   └── Basic DSA
│
├── Medium
│   └── Greedy
│
└── Hard
    └── Dynamic Programming
```

Recent candidate experience from 2025 also reported a 3-hour test with three coding questions at easy, medium and hard levels.

InfyTQ is a separate Infosys certification/hiring ecosystem and should **not** be mixed with the general System Engineer aptitude pattern.

```text
Duration: 3 hours

└── DBMS — 10
```

### Advantage Round

```text
Duration: 3 hours

└── Coding — 3 questions
```

These details come from placement-preparation reporting and may change by batch/program.

# 9. Important Notes

### Rule 1

Do not assume that the 2025 pattern will remain unchanged.

### Rule 2

Check the specific:

```text
Infosys Job Description
        +
TPO / Recruitment Email
        +
Assessment Instructions
```

before the exam.

### Rule 3

Do not mix these as one exam:

```text
General Infosys Fresher Assessment
HackWithInfy
InfyTQ
Specialist Programmer hiring
```

They can have substantially different assessment formats.

### Rule 4

For aptitude preparation, the common foundation remains:

```text
Quant + Reasoning + Verbal
```

Then add:

```text
Pseudocode + Programming + Writing
```

for drives where those sections are present.
