# TCS NQT — Exam Pattern

> **Important:** TCS NQT patterns can change by hiring cycle. The current official TCS careers page should be treated as the final authority. Any detail marked **verify on the official site** should be checked again before the actual exam.

## Current Officially Published Structure

According to the current TCS All India NQT hiring information:

| Part | Section | Duration |
|---|---|---:|
| Part A — Foundation | Numerical Ability | 25 min |
| Part A — Foundation | Verbal Ability | 25 min |
| Part A — Foundation | Reasoning Ability | 25 min |
| Part B — Advanced | Advanced Quantitative & Reasoning Ability | 25 min |
| Part B — Advanced | Advanced Coding | 90 min |
| **Total** | **Foundation + Advanced** | **190 min** |

TCS describes the assessment as an integrated test with:

- **Foundation:** 75 minutes
- **Advanced:** 115 minutes
- **Total:** 190 minutes

The official page states that the Advanced section is mandatory for candidates aspiring for Digital or Prime offers.

The official TCS page confirms the section structure and durations but does **not** provide a fixed per-section question count on the page currently available.

# Part B — Advanced

### Advanced Quantitative & Reasoning Ability

This is intended to test more advanced problem-solving ability than the Foundation aptitude sections.

Preparation should include:

- Advanced arithmetic
- Advanced quantitative reasoning
- Data interpretation
- Logical reasoning
- Multi-step aptitude problems
- Higher-difficulty problem solving

Exact syllabus and topic weightage: **verify on the official site**.

### Advanced Coding

The official TCS page currently specifies:

- **90 minutes**
- Advanced Coding section
- Advanced section total = 115 minutes

Exact number of coding problems and detailed marking scheme: **verify on the official site**.

# Difficulty

TCS does not provide a permanent official "Easy/Medium/Hard" label for every aptitude topic.

For preparation purposes, a practical classification is:

| Area | Preparation Level |
|---|---|
| Foundation Numerical Ability | Easy → Moderate → Hard |
| Foundation Verbal Ability | Easy → Moderate |
| Foundation Reasoning Ability | Easy → Moderate → Hard |
| Advanced Quantitative & Reasoning | Moderate → Hard |
| Advanced Coding | Moderate → Hard |

These are preparation-oriented descriptions, not official TCS difficulty ratings.
