# 1. Overview

**TCS NQT (National Qualifier Test)** is used by TCS to assess candidates for entry-level technology hiring.

For the current **TCS All India NQT 2026 hiring cycle**, TCS describes the assessment as an **integrated 190-minute test** divided into:

1. **Foundation Section — 75 minutes**
2. **Advanced Section — 115 minutes**

The Advanced Section is mandatory for candidates aspiring to **Digital or Prime** opportunities.

```text
                    TCS NQT
                       │
          ┌────────────┴────────────┐
          │                         │
     FOUNDATION                  ADVANCED
       75 min                    115 min
          │                         │
    ┌─────┼─────┐             ┌────┴────┐
    │     │     │             │         │
 Numerical Verbal Reasoning   Advanced   Advanced
 Ability   Ability Ability    Quant &    Coding
                             Reasoning
```

# 2. Official Exam Pattern

## Current TCS NQT Integrated Pattern

| Part       | Section                                   |    Duration |
| ---------- | ----------------------------------------- | ----------: |
| **Part A** | Foundation                                |  **75 min** |
|            | Numerical Ability                         |      25 min |
|            | Verbal Ability                            |      25 min |
|            | Reasoning Ability                         |      25 min |
| **Part B** | Advanced                                  | **115 min** |
|            | Advanced Quantitative & Reasoning Ability |      25 min |
|            | Advanced Coding                           |      90 min |
| **Total**  | Integrated Test                           | **190 min** |

**Source:** TCS official All India NQT hiring notice.

### Important

TCS's official hiring page specifies the **section structure and timings**, but does **not** provide a fixed official question count for every subsection on that page.

Therefore, do not treat coaching-site question counts as guaranteed exam specifications.

# 5. Official Syllabus

The official TCS iON NQT Cognitive description gives the following broad assessment areas:

| Section               | Officially described areas                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Verbal Ability**    | English grammar, appropriate usage, reading comprehension                                                                            |
| **Reasoning Ability** | Word/numeric patterns, problem solving, figural/factual analysis, decision making, propositional reasoning, visual-spatial reasoning |
| **Numerical Ability** | Number system, arithmetic, elementary statistics, data interpretation                                                                |

### Important distinction

```text
OFFICIAL SYLLABUS
       │
       ├── Broad abilities published by TCS/TCS iON
       │
       ▼
PREPARATION SYLLABUS
       │
       ├── Individual topics used by preparation platforms
       ├── Historical/recalled question patterns
       └── Practice categories
```

**Do not confuse a coaching site's topic list with an official guaranteed question distribution.**

# 7. Important Exam Rules

## 7.1 Integrated Test

TCS describes the assessment as one integrated test containing Foundation and Advanced sections.

## 7.2 Advanced Requirement

The Advanced Section is mandatory for candidates aspiring to **Digital or Prime** opportunities.

## 7.3 Test Mode

For the 2026 All India NQT hiring notice, TCS states that the test is conducted at allotted **TCS iON Centres**.

## 7.4 Language

TCS iON states that its NQT tests are conducted in **English** and that there is no negative marking for the NQT variants described on its platform.

> **Note:** Always check the specific hiring notification for your drive because TCS can modify assessment details between hiring programs.

# 8. Foundation vs Advanced

| Feature                 | Foundation        | Advanced                              |
| ----------------------- | ----------------- | ------------------------------------- |
| Main purpose            | Core aptitude     | Higher-level aptitude + coding        |
| Duration                | 75 min            | 115 min                               |
| Quant                   | Numerical Ability | Advanced Quantitative                 |
| Reasoning               | Reasoning Ability | Advanced Reasoning                    |
| Verbal                  | Yes               | No separate verbal section            |
| Coding                  | No                | Yes                                   |
| Digital/Prime relevance | Required          | Mandatory to aspire for Digital/Prime |

Official section structure: TCS All India NQT hiring notice.

```text
                    TCS NQT
                       │

              FOUNDATION BASICS
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
       QUANT        REASONING      VERBAL
          │            │            │
          └────────────┼────────────┘
                       ▼
                SECTIONAL TESTS
                       │
                       ▼
              ADVANCED APTITUDE
                       │
                       ▼
                ADVANCED CODING
                       │
                       ▼
                 FULL MOCKS
                       │
                       ▼
```

### Recommended order

1. **Quantitative basics**
2. **Reasoning basics**
3. **Verbal fundamentals**
4. **Topic-wise practice**
5. **TCS-reported/recalled questions**
6. **Sectional mocks**
7. **Advanced Quant + Reasoning**
8. **Advanced Coding**
9. **Full-length mocks**
