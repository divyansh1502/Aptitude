## 📌 What This Repository Is

This repository is a structured roadmap for preparing aptitude tests
used in:

-   TCS NQT / TCS iON
-   Infosys
-   Wipro
-   Accenture
-   Cognizant
-   Capgemini
-   Tech Mahindra
-   HCLTech
-   AMCAT-based hiring
-   CoCubes-based assessments
-   Other campus and off-campus fresher assessments

The goal is **not** to memorize one company's question bank.

The goal is to build a **common aptitude foundation** that covers the
topics repeatedly used across company assessments, while separately
tracking company-specific additions.

> **Important:** Companies change test patterns, section names, question
> counts, and difficulty. A topic being absent from an official public
> syllabus does **not** prove that the topic can never appear in a
> particular drive.

# 1. Research Methodology

This roadmap separates information into three levels:

### 🟢 Level 1 --- Officially documented

Topics and sections explicitly stated by the assessment provider or
company.

Example:

TCS iON NQT Cognitive officially describes:

-   Numerical Ability
-   Verbal Ability
-   Reasoning Ability

Its published coverage includes number system, arithmetic, elementary
statistics, data interpretation, English grammar, reading comprehension,
pattern recognition, problem solving, decision making, propositional
reasoning, and visual/spatial reasoning.

### 🟡 Level 2 --- Repeatedly reported pattern

Topics repeatedly reported by current preparation sources, previous
candidates, or assessment-preparation platforms.

These are useful for preparation, but they should not be treated as an
official fixed blueprint.

### 🔴 Level 3 --- Drive-specific / uncertain

A topic may appear in some company drives but not others.

Therefore:

> **Prepare the common core first. Add company-specific topics only
> after the core is strong.**

# 2. TCS NQT --- Core Reference

## TCS NQT IT

TCS's published IT assessment is divided into:

### Part A --- Foundation

-   Numerical Ability
-   Verbal Ability
-   Reasoning Ability
-   75 minutes total

### Part B --- Advanced

-   Advanced Quantitative & Reasoning Ability
-   Advanced Coding
-   115 minutes total

The official TCS page currently describes the integrated test as **190
minutes**.

The Advanced section is important for candidates targeting Digital or
Prime-style outcomes in the TCS NQT hiring process.

### TCS iON Cognitive

The separate TCS iON Cognitive assessment officially covers:

#### Numerical Ability

-   Number System
-   Arithmetic
-   Elementary Statistics
-   Data Interpretation

#### Verbal Ability

-   English Grammar
-   Reading Comprehension

#### Reasoning Ability

-   Word and Numeric Patterns
-   Problem Solving
-   Figural and Factual Analysis
-   Decision Making
-   Propositional Reasoning
-   Visual/Spatial Reasoning

This means the safest TCS-first preparation strategy is:

> **Arithmetic + Number System + DI + Grammar + RC + Core
> Logical/Analytical Reasoning**

Then expand into the broader company-placement syllabus.

# 6. Topics Not Explicitly Listed vs Never Asked

This distinction is extremely important.

## ❌ Do NOT create a list called "Topics Never Asked"

There is no reliable universal list of aptitude topics that are
**never** asked across all companies.

Instead, use this classification:

### A. Officially listed

The assessment provider explicitly mentions the topic.

### B. Commonly reported

The topic repeatedly appears in preparation material, previous-paper
discussions, or candidate reports.

### C. Not explicitly listed

The topic is not named in the current public syllabus.

### D. Drive-dependent

The topic has appeared in some hiring drives but is not consistently
part of every drive.

------------------------------------------------------------------------

## Example: TCS

TCS iON's official Cognitive syllabus explicitly names:

-   Number System
-   Arithmetic
-   Elementary Statistics
-   Data Interpretation
-   English Grammar
-   Reading Comprehension
-   Word/numeric patterns
-   Problem solving
-   Figural/factual analysis
-   Decision making
-   Propositional reasoning
-   Visual/spatial reasoning

Topics such as:

-   Permutation & Combination
-   Advanced Probability
-   Coordinate Geometry
-   Clocks
-   Calendars

are **not individually named in that official Cognitive syllabus**.

That does **not** mean they are impossible in every TCS-related
assessment.

# 10. Revision System

Aptitude is not only about learning.

It is about **retaining patterns**.

For every topic maintain:

``` text
Topic
├── Formula Sheet
├── Shortcut
├── Common Patterns
├── Mistakes
├── 5 Representative Questions
└── Revision Date
```

## Suggested Revision Cycle

``` text
Day 0  → Learn
Day 1  → Quick revision
Day 3  → Practice
Day 7  → Timed test
Day 14 → Mixed revision
Day 30 → Full mock
```

# 11. Mock-Test Strategy

Do not start with full mocks every day.

Use:

### Level 1

Topic-wise tests

### Level 2

Sectional tests

-   Quant
-   Reasoning
-   Verbal

### Level 3

Company-specific tests

### Level 4

Full aptitude mock

### Level 5

Full company assessment

------------------------------------------------------------------------

## Mock Analysis

After every mock, classify every wrong question:

``` text
C = Concept mistake
S = Silly mistake
T = Time problem
R = Reading mistake
G = Guess
```

Your goal is not merely to increase mock scores.

Your goal is to reduce repeated mistakes.

# 13. What NOT to Do

## ❌ Do not memorize formulas without understanding

For example, don't memorize:

``` text
Distance = Speed × Time
```

and stop there.

Understand the relationship between all three variables.

------------------------------------------------------------------------

## ❌ Do not solve only one company

A better approach is:

``` text
Common Core
      ↓
TCS / Infosys / Wipro / Accenture
      ↓
Company-specific topics
      ↓
Mocks
```

------------------------------------------------------------------------

## ❌ Do not spend 3 days on one rare topic

If you have not mastered:

-   Percentages
-   Ratio
-   Average
-   Profit/Loss
-   Time & Work
-   TSD
-   Number System

then advanced mathematics should not be your priority.
