## 📌 Overview

This repository is a roadmap for the aptitude rounds used by:

| | | | |
|---|---|---|---|
| **TCS NQT / iON** | **Infosys** | **Wipro** | **Accenture** |
| **Cognizant** | **Capgemini** | **Tech Mahindra** | **HCLTech** |
| **AMCAT** | **CoCubes** | Other campus & off-campus drives | |

The goal is **not** to memorise one company's question bank. The goal is to build a **common aptitude foundation** that covers topics repeated across assessments, and then track company-specific additions separately.

> [!IMPORTANT]
> Companies change patterns, section names, question counts and difficulty. A topic missing from an official syllabus does **not** prove it can never appear. Always check your own assessment invite.

### 🧭 How reliable is each piece of information?

| Level | Meaning | How to use it |
|:---:|---|---|
| 🟢 **Official** | Stated by the company / assessment provider | Treat as the baseline |
| 🟡 **Commonly reported** | Repeated in prep platforms and candidate reports | Prepare, but don't treat as fixed |
| 🔴 **Drive-specific** | Appeared in some drives only | Add after the core is strong |

## 📚 Master Syllabus

### 🔢 Quantitative Aptitude

<details open>
<summary><b>Foundation (do these first)</b></summary>

| Topic | Subtopics |
|---|---|
| **Number System** | Types of numbers, divisibility, factors, primes, remainders, unit digit, cyclicity |
| **HCF & LCM** | Relationship, word problems, fractions |
| **Fractions, Powers & Roots** | Operations, recurring decimals, indices, surds, approximation |
| **Percentages** | Increase/decrease, successive change, reverse percentage, population & salary problems |
| **Ratio & Proportion** | Direct/inverse, compound ratio, partnership |
| **Averages** | Weighted, addition/removal/replacement, combined average |
| **Profit, Loss & Discount** | CP/SP/MP, successive discounts, false weights |
| **Simple & Compound Interest** | Half-yearly/quarterly compounding, SI vs CI difference |
| **Time & Work** | Efficiency, alternate work, wages |
| **Time, Speed & Distance** | Relative speed, average speed, trains, boats & streams |

</details>

<details>
<summary><b>Expansion (add after the foundation)</b></summary>

| Topic | Subtopics |
|---|---|
| **Pipes & Cisterns** | Filling, emptying, leaks |
| **Mixtures & Alligation** | Replacement, weighted mixture, concentration |
| **Ages** | Present/past/future, ratios |
| **Algebra** | Linear, simultaneous, quadratic, inequalities |
| **Progressions** | AP, GP, series sums |
| **Permutation & Combination** | Counting principle, arrangements, selections |
| **Probability** | Basic, complementary, independent, conditional basics |
| **Geometry & Mensuration** | Triangles, circles, polygons, area, surface area, volume |

</details>

<details>
<summary><b>Drive-dependent (only if your target needs them)</b></summary>

Logarithms · Coordinate Geometry · Clocks · Calendars · Advanced Probability · Advanced P&C

</details>

## 🗓️ Study Plan

### Recommended learning order

```text
Stage 1  Quant foundation   Number System → HCF/LCM → Simplification → Percentages → Ratio
                            → Average → Profit & Loss → SI/CI → Time & Work → TSD

Stage 2  Logical foundation Analogy → Classification → Number Series → Alphabet Series
                            → Coding-Decoding → Blood Relations → Directions → Ranking
                            → Syllogism → Statement & Conclusion

Stage 3  Verbal foundation  Parts of Speech → Tenses → SV Agreement → Articles → Prepositions
                            → Pronouns → Error Spotting → Sentence Correction → Vocabulary → RC

Stage 4  Expansion          Mixtures → Ages → Pipes → Boats → P&C → Probability → Geometry
                            → Mensuration → Progressions → Puzzles → Seating → Data Sufficiency
                            → Para Jumbles → Advanced DI
```

### Practice rounds (per topic)

| Round | Goal | Volume |
|:---:|---|---|
| **1** | Learn the concept | 10–15 untimed questions |
| **2** | Pattern recognition | 20–30 mixed questions |
| **3** | Speed | 20 questions against a timer |
| **4** | Company questions | Previous-year style sets |

### Revision cycle

```text
Day 0   Learn
Day 1   Quick revision
Day 3   Practice
Day 7   Timed test
Day 14  Mixed revision
Day 30  Full mock
```

For every topic, keep: **formula sheet · shortcuts · common patterns · mistakes · 5 representative questions · revision date**.

### Mock-test ladder

`Topic tests` → `Sectional tests` → `Company-specific tests` → `Full aptitude mock` → `Full company assessment`

Tag every wrong answer after each mock:

| Tag | Meaning |
|:---:|---|
| **C** | Concept mistake |
| **S** | Silly mistake |
| **T** | Time problem |
| **R** | Reading mistake |
| **G** | Guess |

> The aim is not a higher mock score. It is **fewer repeated mistakes**.

### 🚫 Avoid these

- Memorising formulas without understanding the relationship behind them.
- Preparing for one company only. Build the common core first.
- Spending days on a rare topic before Percentages, Ratio, Average, Profit/Loss, Time & Work, TSD and Number System are solid.
- Judging progress by volume. 300 analysed questions beat 1000 random ones.
