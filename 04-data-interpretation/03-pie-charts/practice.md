# 📝 Data Interpretation — Pie Charts Practice

> Placement-focused practice covering angle, percentage, ratio, total, comparison, and multiple pie charts.

## 📌 Instructions

* Target time: **30 minutes**
* Solve without a calculator first.
* Write the formula before difficult calculations.
* Pay special attention to questions where total values differ.

---

# 🟢 Set 1 — Basic Pie Chart

A pie chart represents the distribution of **800 students**.

| Category    | Angle |
| ----------- | ----: |
| Engineering |   90° |
| Medical     |   72° |
| Commerce    |  108° |
| Arts        |   54° |
| Others      |   36° |

### Q1. How many students are in Engineering?

### Q2. How many students are in Medical?

### Q3. What percentage of students are in Commerce?

### Q4. Find the number of Arts students.

### Q5. Find the ratio of Engineering to Commerce students.

### Q6. Find expenditure on salaries.

### Q7. Find expenditure on marketing.

### Q10. Find the ratio of operations to others.
