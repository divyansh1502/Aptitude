# 1. C — Calculation Mistakes

Calculation mistakes occur when the required data is identified correctly but arithmetic is wrong.

### Common Examples

* Addition error
* Subtraction error
* Multiplication error
* Division error
* Decimal error
* Fraction simplification error
* Percentage calculation error

### Example

```text
Correct:
240 / 600 × 100 = 40%

Mistake:
240 / 600 × 100 = 4%
```

### Prevention

* Write intermediate values clearly.
* Cancel fractions before multiplying.
* Recheck suspicious calculations.
* Use estimation to verify the final answer.

---

# 2. S — Selection Mistakes

Selection mistakes happen when you use the **wrong cells or wrong data** from the table.

### Common Examples

* Using 2023 instead of 2024
* Using Company B instead of Company C
* Using revenue instead of profit
* Using one month instead of the total period

### Example

Question:

> Find the percentage increase from 2022 to 2023.

Mistake:

Using 2021 and 2023.

### Prevention

Before calculating, identify:

```text
Row:
Column:
Year:
Required values:
```

---

# 3. T — Table Reading Mistakes

These happen when the table itself is misunderstood.

### Common Examples

* Ignoring units
* Confusing rows and columns
* Misreading headings
* Missing a condition in the question
* Confusing lakh and crore
* Treating percentages as raw numbers

### Prevention

Always perform this scan:

```text
1. What do rows represent?
2. What do columns represent?
3. What are the units?
4. What period is given?
5. What exactly is being asked?
```

---

# 4. R — Reasoning Mistakes

The data is read correctly, but the wrong mathematical concept is applied.

### Common Examples

* Using new value instead of original value as denominator
* Confusing ratio with percentage
* Using simple average instead of weighted average
* Confusing difference with percentage difference
* Confusing percentage points with percentage change

### Example

Sales:

```text
Old = 400
New = 500
```

Wrong:

$$
\frac{100}{500}\times100=20\%
$$

Correct:

$$
\frac{100}{400}\times100=25\%
$$

---

# 5. G — Guess / Time Management Mistakes

These happen when you:

* Guess without enough evidence
* Spend too long on one question
* Perform unnecessary calculations
* Ignore easier questions
* Rush because of poor time management

### Prevention

Use:

```text
Read → Identify → Calculate → Verify
```

If a question is taking significantly longer than expected:

> Mark it and move on if the test format allows it.

Return later.

# 🧠 Frequently Repeated Table DI Mistakes

## Mistake 1 — Wrong Percentage Denominator

### Wrong

$$
\frac{Increase}{New}\times100
$$

### Correct

$$
\frac{Increase}{Original}\times100
$$

---

## Mistake 2 — Ratio Reversal

Question:

> Ratio of A to B

Correct:

$$
A:B
$$

Not:

$$
B:A
$$

---

## Mistake 3 — Ignoring Units

If:

> Revenue is given in ₹ crore.

Then:

```text
500 = ₹500 crore
```

not ₹500.

---

## Mistake 4 — Calculating Everything

A table contains 20 values, but the question needs only two.

Do not calculate all 20.

### Rule

> **Calculate only the cells required by the question.**

---

## Mistake 5 — Percentage vs Percentage Points

If a percentage changes from 40% to 50%:

Percentage-point change:

$$
50-40=10
$$

Percentage change:

$$
\frac{10}{40}\times100=25\%
$$

# 🔁 Repeated Mistake Review

At the end of every practice session, classify every wrong answer.

Example:

```text
Total Questions = 20
Correct = 16
Wrong = 4

C = 1
S = 0
T = 1
R = 2
G = 0
```

### Interpretation

If **R** is repeatedly high:

> Revise formulas and question interpretation.

If **T** is repeatedly high:

> Slow down while reading the table.

If **C** is repeatedly high:

> Practice mental arithmetic and calculation accuracy.

If **G** is repeatedly high:

> Work on time management and question selection.
