# 🟢 Set 1 — Basic Table DI

The following table shows the number of students enrolled in five courses.

| Course     | 2023 | 2024 |
| ---------- | ---: | ---: |
| Java       |  120 |  150 |
| Python     |  100 |  140 |
| C++        |   80 |  100 |
| JavaScript |  150 |  180 |
| SQL        |   50 |   70 |

### Q1. What is the total number of students enrolled in Java in both years?

### Q2. What is the difference between JavaScript enrollment in 2024 and C++ enrollment in 2024?

### Q3. What is the ratio of Python enrollment in 2024 to SQL enrollment in 2024?

### Q4. What is the percentage increase in Java enrollment from 2023 to 2024?

### Q5. What is the total enrollment in all courses in 2023?
