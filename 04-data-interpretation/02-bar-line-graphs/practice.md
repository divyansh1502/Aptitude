# 📝 Data Interpretation — Bar & Line Graph Practice

> Practice questions covering bar graphs, double bar graphs, line graphs, percentages, ratios, averages, trends, and graph scales.

## 📌 Instructions

* Solve without a calculator initially.
* Read the graph/values carefully.
* Check the scale before calculating.
* Target time: **30 minutes**.
* Try to achieve **90%+ accuracy** before focusing heavily on speed.
